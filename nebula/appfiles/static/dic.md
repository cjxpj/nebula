## 一、认识词库

> 编写 `.n` 词库脚本时应遵守的约定，目的是保持词库可读、可维护、可复用。

### 文件规范

- 词库脚本统一使用 `.n` 后缀；对外输出网页的 Web 词库使用 `.wn` 后缀。
- 文件统一使用 UTF-8 编码。
- 按用途放入对应目录：
  - `private/` 资源目录：存放重要资源与词库；
  - `public/` 词库目录：公开可访问；
  - `database/` 储存目录：数据读写；
  - 机器人词库放 `<账号路径>/dic/`，仅 `.n` 后缀会被执行，其余后缀（`.md`/`.txt`/`.json` 等）自动跳过，可放心存放说明文档。
- 建议按功能拆分文件，避免把大量触发词堆在单个文件。

### 触发词规范

- 触发词独占一行，正文紧跟其下。
- 入口触发词统一使用 `Main`。
- 普通触发词用简短明确的文字；需要模糊匹配时使用正则，如 `测试 .+`。
- 匹配文本按空格分割可用 `%参数0%`、`%参数1%` 读取；正则捕获组可用 `%括号0%`（整体）、`%括号1%`（第一组）读取。
- 定义函数用 `[函数]名称`（可加参数规则 `[函数|1|2]名称`），定义内部回调用 `[内部]名称`（用 `$回调 名称$` 触发）。
- 特殊触发用 `[类别]触发词` 定义，其中 `类别` 为任意自定义名称（如 `[按钮事件]同意`），由对应事件框架主动派发。

### 书写风格

- 变量赋值用 `键:值`，读取用 `%键%`。
- 调用函数用 `$函数名 参数1 参数2$`。
- 注释用 `//`（单行）或 `/* */`（多行）。
- 正文建议统一缩进（4 空格），判断/循环/函数框等块结构内尤其要保持一致。
- 参数含空格时用 `"..."` 包裹为一个整体。
- 多行内容优先用结构化写法：`文本>...<文本`、`JSON>...<JSON`、`函数>...<函数`、`<?n ... ?>`（或 `#{ ... }#`），避免依赖裸换行。

### 引入指令规范

- `#引入=` 是预编译指令，必须放在词库文件头部。
- 引入本地文件：`#引入=dic/a.n`；引入整个目录：`#引入=dic/*`。
- 引入机器人函数：`#引入=@QQBot`、`#引入=@NapCat` 等，可多行引入多个。
- 引入文件并返回实例包：`变量:#引入=目标`。

### 变量命名规范

- 变量名、触发词、函数名使用有意义的中文或英文。
- 避免使用下划线 `_` 开头结尾的命名，该形式保留给系统魔术变量（如 `%_词库路径_%`、`%_继承_%`）。
- 变量名（键名）长度最多 32 字节（按 UTF-8 字节计，中文一个汉字占 3 字节），超出该长度将无法被识别为赋值变量。

### 注意事项

- 循环框留空为死循环（`循环>i`），务必在循环体内提供 `>终止` 或 `>终止循环` 退出条件。
- 机器人主动发送函数需先在头部 `#引入=@机器人`；回复函数由消息框架自动注入，无需引入。
- 输出网页内容时，记得用 `$全局变量 输出类型 ...$` 或 `$设置头部 ...$` 设置正确的 Content-Type。

##### 参数数量

> 函数统一按**函数名精确匹配**（不再使用正则），并校验参数个数；参数规则用 `[函数|规则]名称` 声明，未声明 `|规则` 时默认 0 个参数（等价于 `[函数|0]名称`）。
> 规则与内置函数一致：`1`（恰好 1 个）、`1|2`（1 到 2 个）、`1..`（1 到无限个）、`..3`（最多 3 个）等，可组合如 `1|3|5..`。
> 类函数同样支持，写作 `[函数:类名|规则]名称`。
> 函数名为纯标识符，不支持空格或特殊符号（如 `.`、`%`、`|`、`->` 等），否则会与参数分隔、对象方法、变量传出等语法冲突。
> 参数数量不符时与内置函数一致：输出 `参数数量错误` 并停止执行，不会静默返回原文。

```
Main
$计算 5$
$计算 5 6$
$打招呼 世界$

[函数|1|2]计算
%参数1%

[函数|1..]打招呼
你好，%参数1%
```

> 未声明 `|规则` 时默认 0 个参数：`[函数]名称` 等价于 `[函数|0]名称`，调用时带参数会报 `参数数量错误`。

### Class

这个相当于面对象功能，可用 `$new$` 创建独立实例。

> Class（类）通过触发词前缀 `[]` 中的 `:类名` 后缀声明：`[函数:类名]`、`[内部:类名]`，也支持任意特殊触发 `[类别:类名]`。
> `[F:类名]` / `[f:类名]` 自动归一为 `[函数:类名]`，`[L:类名]` / `[l:类名]` 自动归一为 `[内部:类名]`。
> 未加 `:类名` 时即为普通全局函数/内部/特殊触发。
> 读取类变量用 `%类名.变量%`（类内可用 `%自己.变量%`）；写入成员变量在类内用 `.变量:值`。
> 类内可定义 `[内部:类名]名称` 回调，在类方法内部用 `$回调 名称$` 触发（详见「回调」章节）。

```
[函数:我的包]设置变量 .*
.变量:%参数1%

[函数:我的包]读取变量
%自己.变量%

Main
// 执行 Class 函数
$.我的包 设置变量 成功$
$.我的包 读取变量$
// Class 中读取变量
%我的包.变量%
```

#### 创建实例

> `$new 类名$` 创建类的一个新实例，复制源类变量（相互独立），函数/内部定义共享。
> 创建后自动执行构造函数 `[函数:类名]new`（如定义），并返回实例数据。
> 实例数据可赋值给变量，再用 `%变量.成员%` 读取、`$变量.方法$` 调用（等价 `$.变量 方法$`）。

```
[函数:我的包]new
.变量:初始值

[函数:我的包]设置变量 .*
.变量:%参数1%

Main
// 创建实例并执行构造函数 new
甲:$new 我的包$
乙:$new 我的包$

$甲.设置变量 甲的值$
$乙.设置变量 乙的值$

// 通过变量读取实例成员（各自独立）
%甲.变量%
%乙.变量%
```

### 引入

> `#引入=` 是**预编译指令**，在编译期处理，不会出现在运行时词行中。  
> 支持引入本地词库文件，以及注入机器人函数。
> 循环引入（如 A 引入 B、B 又引入 A）会被检测，跳过重复加载避免无限递归；调试面板（DicDebug）会以黄色警告展示，后端日志不打印。

#### 引入文件并返回实例包

> `变量:#引入=目标` 是 `#引入=` 的**赋予值形式**：先按 `#引入=目标` 引入本地词库文件（或 `@机器人`），再把本次引入的**全部函数**（全局函数、类方法、机器人函数）打包成一个实例赋给变量，之后可用 `$变量.方法$` 调用。

### 解析与转换

#### HTML解析

> 解析 HTML，根据路径获取节点。容器节点（含子元素）返回 JSON 节点数组，叶子节点（纯文本）返回文本数组。末尾数字参数作为索引选取单个节点。

```

<!DOCTYPE html>
<html>
    <head>
        <title>标题</title>
    </head>
    <body>
        <h1>文本</h1>
        <h1>文本2</h1>
        <p>文本2</p>
    </body>
</html>
"""

// 不指定路径 → 返回完整 JSON 树
$HTML解析 %a%$

// 叶子节点 → 文本数组
$HTML解析 %a% html head title$    // ["标题"]
$HTML解析 %a% html body h1$       // ["文本","文本2"]
$HTML解析 %a% html body p$        // ["文本2"]

// 容器节点 → JSON 节点数组
$HTML解析 %a% html body$          // [{h1节点},{h1节点},{p节点}]

// 索引选取单个 → 叶子返回文本，容器返回 JSON 对象
$HTML解析 %a% html body h1 0$     // "文本"
$HTML解析 %a% html body h1 1$     // "文本2"
$HTML解析 %a% html body 0$        // {h1节点JSON}
```

### 编码与加密

#### AES

> AES 是一种对称加密算法，支持多种加密模式

**密钥长度**：16/24/32 字节（对应 AES-128/AES-192/AES-256）

| 模式 | 说明 | 安全性 | IV要求 |
| :--: | :-- | :--: | :--: |
| **GCM** | 认证加密（推荐） | ✅ 高 | 自动生成 |
| **CTR** | 计数器模式 | ⚠️ 中 | 需提供16字节 |
| **CBC** | 密码块链模式 | ⚠️ 中 | 需提供16字节 |
| **CFB** | 密码反馈模式 | ❌ 低（已弃用） | 需提供16字节 |

##### GCM 模式（推荐）

> GCM 是认证加密模式，提供加密和完整性验证，推荐用于安全通信

```
$AES_GCM加密 密钥 明文$
$AES_GCM解密 密钥 密文$
```

##### CTR 模式

> CTR 模式是流加密模式，高效且可并行化，但不提供认证

```
$AES_CTR加密 密钥 IV 明文$
$AES_CTR解密 密钥 IV 密文$
```

##### CBC 模式

> CBC 模式是传统的块加密模式，需要填充

```
$AES_CBC加密 密钥 IV 明文$
$AES_CBC解密 密钥 IV 密文$
```

##### CFB 模式（已弃用）

> 不推荐使用，仅保留向后兼容

```
$AES_CFB加密 密钥 IV 明文$
$AES_CFB解密 密钥 IV 密文$
```

**IV 说明**：
- IV（初始化向量）必须与密钥一起保存
- 不同加密操作应使用不同的 IV
- GCM 模式的 nonce 会自动附加到密文中

### MySQL

`$新建mysql$` 返回一个「MySQL 连接对象」（面对像，惰性连接，创建时不会立即连接），后续通过 `$对象.方法$` 操作。

**创建连接**（地址支持 `host` 或 `host:端口`，端口默认 3306）

```

连接:$新建mysql root 941331b62d54a7f7 172.20.167.249$
连接:$新建mysql root 941331b62d54a7f7 172.20.167.249:3307$
```

**检测连接**（返回 "true" / "false"）

```

```

**切换默认数据库**（后续写/读/删除操作使用该库）

```
$连接.切换数据库 数据库名称$
```

**执行 SQL**（返回 JSON，见下方返回结构说明；执行带数据库名的 SQL 会自动记住该库）

```
sql::CREATE DATABASE 数据库名称;
$连接.执行 %sql%$
```

```
sql::INSERT INTO 表 (name, data) VALUES (?, ?)
$连接.执行 数据库名称 %sql% 绑定内容1 绑定内容2$
```

**快捷读写**（需先切换数据库或执行过带数据库名的 SQL）

```
$连接.写 表单 键 值$
$连接.读$               // 获取全部表单（JSON 数组）
$连接.读 表单$           // 获取全部键（JSON 数组）
$连接.读 表单 键$        // 读取值
$连接.读 表单 键 默认值$  // 读取，不存在返回默认值
$连接.删除文件 键$       // 删除 fs_files 表中记录
$连接.删除文件夹 键$     // 删除 fs_files 表中记录
```

**关闭连接**（返回 "true"）

```
$连接.关闭$
```

`$连接.执行$` 返回 JSON 结构：

```json
{
  "error": "",
  "last_insert_id": 0,
  "rows_affected": 1,
  "data": [{"列名":"值"}]
}
```

- `data`：仅查询语句返回，为结果行数组
- `rows_affected` / `last_insert_id`：仅非查询语句返回

**入群申请处理**

通过 `入群审批` 同意或拒绝入群申请：

```
// 同意入群（ReplyFuncs，%群号% 群OpenID，%QQ% 为申请人 OpenID，%申请ID% 为审批令牌）
$入群审批 %群号% %QQ% 同意 %申请ID%$

// 拒绝入群并附带拒绝理由（ReplyFuncs）

// 拒绝入群并同时加入群黑名单（ReplyFuncs，op 传 拉黑拒绝）
$入群审批 %群号% %QQ% 拉黑拒绝 %申请ID% 不符合入群条件$

// 主动审批（ActiveFuncs，需 #引入=@QQBot）

**消息按钮（Keyboard）**

`发送MD` 通过 `按钮` 关键字分隔按钮定义，按钮使用参数串格式传递。第二参数为 JSON（`{"rows":[...]}` 或 `{"id":"..."}`）时自动解析为键盘。自定义按钮仅支持简单文本模式（`$发送MD <Markdown内容> 按钮 ...$`）；模板模式（`$发送MD <模板ID> <键1> <值1>...`）不支持自定义按钮，仅插入文本，键/值可正常使用"按钮"字样：

```
// [样式数字]标签[|数据]（\r 后缀换行；样式 [0]~[3]，默认 [0]）
$发送MD "# 标题\n内容" 按钮 [1]确认|/确认 [0]取消|/取消\r$

// 简写：标签|数据，自动推断类型
$发送MD "# 菜单" 按钮 查看详情|https://example.com 确认|#回调操作$
// → "查看详情" 外显为链接网址，"确认" 外显为回调按钮 data=回调操作

// data 以 # 开头自动为回调（type=1），触发词格式：[按钮事件]data
$发送MD "# 请确认" 按钮 确认|#确认操作 取消|#取消操作$

// 对应的回调触发词定义
[按钮事件]确认操作
%QQ% 已确认

[按钮事件]取消操作
%QQ% 已取消

// 模板模式不支持自定义按钮，仅插入文本，"按钮"可正常作为键/值
$发送MD 模板ID key val 按钮 了解更多$
```

按钮 type（由 data 前缀自动推断）：`0`=跳转链接（data 以 http 开头），`1`=回调（data 以 `#` 开头），`2`=指令（默认，输入框自动填充 data）
按钮样式（开头 `[数字]`）：`0`=灰色线框（默认），`1`=蓝色线框
按钮 permission.type：`0`=指定用户，`1`=仅管理者，`2`=所有人

**JSON 键盘**（`发送MD` 第2参数 与 `群单发MD` 第4参数均支持）：
```
$发送MD "# 标题" {"rows":[{"buttons":[{"id":"1","render_data":{"label":"确认","visited_label":"已确认","style":1},"action":{"type":2,"permission":{"type":2},"data":"/确认","enter":true}}]}]}$
$群单发MD 1 群OpenID "# 标题" {"rows":[{"buttons":[{"id":"1","render_data":{"label":"确认","visited_label":"已确认","style":1},"action":{"type":2,"permission":{"type":2},"data":"/确认","enter":true}}]}]}$
$群单发MD 1 群OpenID "# 标题" {"id":"123456"}$
```

**按钮回调事件**

action.type=1（回调按钮）点击后触发 `INTERACTION_CREATE` 事件，框架自动回应并转为词库消息处理。触发词格式为 `[按钮事件]<data>`（`/` 前缀会被剥离），支持 `%QQ%（点击者）` / `%群号%` / `%来源%（=按钮）` 等事件变量。

可通过 `$设置状态 <状态码>$` 控制按钮交互的返回结果：
- `0`：成功（默认）
- `1`：操作失败
- `2`：操作频繁
- `3`：重复操作
- `4`：没有权限
- `5`：仅管理员操作

```
// 发送带回调按钮的 MD（标签|#数据），data 中 / 前缀会被剥离
$发送MD "# 请确认操作" 按钮 确认|#确认操作 取消|#取消操作$

// 对应的回调触发词定义
[按钮事件]确认操作
已收到 %QQ% 的确认！

[按钮事件]取消操作
%QQ% 取消了操作
```

**词库示例**：
```

$发送MD "# 菜单\n点击按钮确认" 按钮 确认|#确认操作 取消|/取消$

// 监听按钮回调

### SecludedBot 插件协议

#### 配置说明

在 `NebulaData/private/system/config.ini` 中配置：

```ini
[Secluded]
启用 = true
词库 = private/bot/secluded
对接地址 = ws://127.0.0.1:24804
令牌 = SecretToken
```

| 配置项 | 说明 | 默认值 |
| ---- | ---- | ---- |
| 启用 | 是否启用 Secluded 插件 | false |
| 词库 | 词库目录路径 | private/bot/secluded |
| 对接地址 | WebSocket 服务地址 | ws://127.0.0.1:8080 |
| 令牌 | 认证令牌 | 空 |

#### 词库变量

SecludedBot 支持以下词库变量：

| 变量 | 说明 |
| ---- | ---- |
| `%来源%` | 来源类型（群聊/私聊/临时） |
| `%群号%` | 目标群号 |
| `%QQ%` / `%qq%` | 发言者 QQ（大小写不敏感） |
| `%昵称%` | 发言者昵称 |
| `%管理%` | 发言者管理权限：`1`=群主/创建者, `2`=管理员, `0`=普通成员 |
| `%主人%` | 主人列表（admin.txt）中匹配的 QQ 号，不在列表返回 `null` |
| `%MsgId%` | 消息 ID |
| `%robot%` | 机器人账号 |
| `%data%` | 消息完整原始数据 JSON；`[系统]推送` 事件中为推送 Json 数据 |

#### 事件触发

SecludedBot 支持以下事件触发词，可直接在词库中监听：

| 触发词 | 说明 |
| ---- | ---- |
| `[系统]启动` | 插件连接成功时触发（每次客户端重启后触发一次） |
| `[系统]推送` | 收到系统即时推送时触发（System=System 且 InstantPush=InstantPush），`%data%` 为推送 Json 数据 |
| `[内部]断开连接` | 插件断开连接时触发 |
| `[群事件]全体禁言开启` | 群开启全体禁言时触发 |
| `[群事件]全体禁言关闭` | 群关闭全体禁言时触发 |
| `[群事件]成员禁言 0` | 成员被解禁时触发 |
| `[群事件]成员禁言 [0-9]+` | 成员被禁言时触发，`%参数1%` 为禁言秒数 |

> 全体禁言事件可用 `%群号%`；成员禁言/解禁事件可用 `%QQ%`（被操作成员）、`%Op%`（操作者）、`%参数1%`（禁言秒数）。

#### 消息语法

支持的消息语法（与 NapCat 一致）：

| 语法 | 功能 | 示例 |
| ---- | ---- | ---- |
| `±at=QQ号±` | @ 指定用户 | `±at=%QQ%± 你好！` |
| `±img=URL±` | 发送图片 | `±img=https://example.com/pic.png±` |
| `±atMsg=消息ID±` | 引用回复 | `±atMsg=%MsgId%± 收到！` |

### 回调词库函数

在 JavaScript 中，你可以使用 `runDic` 函数来回调词库函数：

```
a:1
--js
// 调用词库函数并获取返回值
var result = runDic('函数名', '参数1', '参数2');
console.log('词库函数返回:', result);

// 异步调用词库函数
runDic('异步函数', '参数', function(callbackResult) {
    console.log('异步回调结果:', callbackResult);
});
--end
```

**参数说明**：
- 第一个参数：词库函数名称
- 后续参数：传递给词库函数的参数
- 最后一个参数（可选）：回调函数，用于接收异步执行结果

**返回值**：
- 同步调用：返回词库函数的执行结果
- 异步调用：无返回值，结果通过回调函数获取
