## 一、快速入门

### 介绍

> 这是一个用于运行 Nebula 语言的平台  
> 拥有良好的语法功能  
> 帮助你更快更便捷开发网站等服务

### 使用说明

```
启动后会生成NebulaData文件夹
请仔细阅读README.md文档进行使用
启动成功后就能访问127.0.0.1:8080进行查看
如果找不到md查看器，可以把md放进public访问进行查看。
```

### AES

> AES 是一种对称加密算法，支持多种加密模式

**密钥长度**：16/24/32 字节（对应 AES-128/AES-192/AES-256）

| 模式 | 说明 | 安全性 | IV要求 |
| :--: | :-- | :--: | :--: |
| **GCM** | 认证加密（推荐） | ✅ 高 | 自动生成 |
| **CTR** | 计数器模式 | ⚠️ 中 | 需提供16字节 |
| **CBC** | 密码块链模式 | ⚠️ 中 | 需提供16字节 |
| **CFB** | 密码反馈模式 | ❌ 低（已弃用） | 需提供16字节 |

##### GCM 模式（推荐）

> GCM 是认证加密模式，提供加密和完整性验证，推荐用于安全通信

```
$AES.GCM加密 密钥 明文$
$AES.GCM解密 密钥 密文$
```

##### CTR 模式

> CTR 模式是流加密模式，高效且可并行化，但不提供认证

```
$AES.CTR加密 密钥 IV 明文$
$AES.CTR解密 密钥 IV 密文$
```

##### CBC 模式

> CBC 模式是传统的块加密模式，需要填充

```
$AES.CBC加密 密钥 IV 明文$
$AES.CBC解密 密钥 IV 密文$
```

##### CFB 模式（已弃用）

> 不推荐使用，仅保留向后兼容

```
$AES.CFB加密 密钥 IV 明文$
$AES.CFB解密 密钥 IV 密文$
```

**IV 说明**：
- IV（初始化向量）必须与密钥一起保存
- 不同加密操作应使用不同的 IV
- GCM 模式的 nonce 会自动附加到密文中

### 解析与转换

#### HTML解析

> 解析 HTML，根据路径获取节点。容器节点（含子元素）返回 JSON 节点数组，叶子节点（纯文本）返回文本数组。末尾数字参数作为索引选取单个节点。

```
a:"""
<!DOCTYPE html>
<html>
    <head>
        <title>标题</title>
    </head>
    <body>
        <h1>文本</h1>
        <h1>文本2</h1>
        <p>文本2</p>
    </body>
</html>
"""

// 不指定路径 → 返回完整 JSON 树
$HTML解析 %a%$

// 叶子节点 → 文本数组
$HTML解析 %a% html head title$    // ["标题"]
$HTML解析 %a% html body h1$       // ["文本","文本2"]
$HTML解析 %a% html body p$        // ["文本2"]

// 容器节点 → JSON 节点数组
$HTML解析 %a% html body$          // [{h1节点},{h1节点},{p节点}]

// 索引选取单个 → 叶子返回文本，容器返回 JSON 对象
$HTML解析 %a% html body h1 0$     // "文本"
$HTML解析 %a% html body h1 1$     // "文本2"
$HTML解析 %a% html body 0$        // {h1节点JSON}
```

**消息按钮（Keyboard）**

`发送MD` 通过 `按钮` 关键字分隔按钮定义，按钮使用参数串格式传递：

```

**按钮回调事件**

action.type=1（回调按钮）点击后触发 `INTERACTION_CREATE` 事件，框架自动回应并转为词库消息处理。触发词为 `"按钮事件 " + data`（data 的 `/` 前缀会被剥离），支持 `%成员%` / `%用户%` / `%群号%` / `%来源%（=按钮）` 等事件变量。

```
// 发送带 type=1 回调按钮的 MD，data 中 / 前缀会被剥离
$发送MD "# 请确认操作" 按钮 确认;type=1;data=/确认操作 取消;type=1;data=/取消操作$

// 简写：标签|#数据，自动为回调
$发送MD "# 请确认操作" 按钮 确认|#确认操作 取消|#取消操作$

// 触发词 = "按钮事件 " + 去 / 或 # 后的 data
按钮事件 确认操作
$发送文本 "已收到 %成员% 的确认！"$

按钮事件 取消操作
$发送文本 "%成员% 取消了操作"$
```

**词库示例**：
```
// 发送带回调按钮的 MD
$发送MD "# 菜单\n点击按钮确认" 按钮 确认;type=1;data=/确认操作 取消;type=2;data=/取消$

// 监听按钮回调（触发词 = "按钮事件 " + data 去 /）
按钮事件 确认操作
$发送文本 已收到 %成员% 的确认！$
```

### SecludedBot 插件协议

#### 配置说明

在 `NebulaData/private/system/config.ini` 中配置：

```ini
[Secluded]
启用 = true
词库 = private/bot/secluded
对接地址 = ws://127.0.0.1:24804
令牌 = SecretToken
```

| 配置项 | 说明 | 默认值 |
| ---- | ---- | ---- |
| 启用 | 是否启用 Secluded 插件 | false |
| 词库 | 词库目录路径 | private/bot/secluded |
| 对接地址 | WebSocket 服务地址 | ws://127.0.0.1:8080 |
| 令牌 | 认证令牌 | 空 |

#### 词库变量

SecludedBot 支持以下词库变量：

| 变量 | 说明 |
| ---- | ---- |
| `%来源%` | 来源类型（群聊/私聊/临时） |
| `%群号%` | 目标群号 |
| `%QQ%` / `%qq%` | 发言者 QQ（大小写不敏感） |
| `%昵称%` | 发言者昵称 |
| `%管理%` | 发言者管理权限：`1`=群主/创建者, `2`=管理员, `0`=普通成员 |
| `%主人%` | 主人列表（admin.txt）中匹配的 QQ 号，不在列表返回 `null` |
| `%MsgId%` | 消息 ID |
| `%robot%` | 机器人账号 |

### 回调词库函数

在 JavaScript 中，你可以使用 `runDic` 函数来回调词库函数：

```
a:1
--js
// 调用词库函数并获取返回值
var result = runDic('函数名', '参数1', '参数2');
console.log('词库函数返回:', result);

// 异步调用词库函数
runDic('异步函数', '参数', function(callbackResult) {
    console.log('异步回调结果:', callbackResult);
});
--end
```

**参数说明**：
- 第一个参数：词库函数名称
- 后续参数：传递给词库函数的参数
- 最后一个参数（可选）：回调函数，用于接收异步执行结果

**返回值**：
- 同步调用：返回词库函数的执行结果
- 异步调用：无返回值，结果通过回调函数获取
