### 加密与编码

#### AES 🔒
> AES 是一种对称加密算法，支持多种加密模式

**密钥长度**：16/24/32 字节（对应 AES-128/AES-192/AES-256）

| 模式 | 说明 | 安全性 | IV要求 |
| :--: | :-- | :--: | :--: |
| **GCM** | 认证加密（推荐） | ✅ 高 | 自动生成 |
| **CTR** | 计数器模式 | ⚠️ 中 | 需提供16字节 |
| **CBC** | 密码块链模式 | ⚠️ 中 | 需提供16字节 |
| **CFB** | 密码反馈模式 | ❌ 低（已弃用） | 需提供16字节 |

##### GCM 模式（推荐）
> GCM 是认证加密模式，提供加密和完整性验证，推荐用于安全通信

```
$AES.GCM加密 密钥 明文$
$AES.GCM解密 密钥 密文$
```

##### CTR 模式
> CTR 模式是流加密模式，高效且可并行化，但不提供认证

```
$AES.CTR加密 密钥 IV 明文$
$AES.CTR解密 密钥 IV 密文$
```

##### CBC 模式
> CBC 模式是传统的块加密模式，需要填充

```
$AES.CBC加密 密钥 IV 明文$
$AES.CBC解密 密钥 IV 密文$
```

##### CFB 模式（已弃用）
> 不推荐使用，仅保留向后兼容

```
$AES.CFB加密 密钥 IV 明文$
$AES.CFB解密 密钥 IV 密文$
```

**IV 说明**：
- IV（初始化向量）必须与密钥一起保存
- 不同加密操作应使用不同的 IV
- GCM 模式的 nonce 会自动附加到密文中

### 回调词库函数
在 JavaScript 中，你可以使用 `runDic` 函数来回调词库函数：

```
a:1
--js
// 调用词库函数并获取返回值
var result = runDic('函数名', '参数1', '参数2');
console.log('词库函数返回:', result);

// 异步调用词库函数
runDic('异步函数', '参数', function(callbackResult) {
    console.log('异步回调结果:', callbackResult);
});
--end
```

**参数说明**：
- 第一个参数：词库函数名称
- 后续参数：传递给词库函数的参数
- 最后一个参数（可选）：回调函数，用于接收异步执行结果

**返回值**：
- 同步调用：返回词库函数的执行结果
- 异步调用：无返回值，结果通过回调函数获取

### 配置说明

在 `NebulaData/private/system/config.ini` 中配置：

```ini
[Secluded]
启用 = true
词库 = private/bot/secluded
对接地址 = ws://127.0.0.1:24804
令牌 = SecretToken
```

| 配置项 | 说明 | 默认值 |
| ---- | ---- | ---- |
| 启用 | 是否启用 Secluded 插件 | false |
| 词库 | 词库目录路径 | private/bot/secluded |
| 对接地址 | WebSocket 服务地址 | ws://127.0.0.1:8080 |
| 令牌 | 认证令牌 | 空 |
