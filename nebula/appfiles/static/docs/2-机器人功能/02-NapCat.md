# NapCat

使用 `$引入 @NapCat$` 后可用：

## 消息发送

| 函数 | 说明 |
| --- | --- |
| `$群单发 <群号> <文本>$` | 发送群消息 |
| `$私聊 <QQ号> <文本>$` | 发送私聊消息 |
| `$发送视频 <群号> <视频数据>$` | 发送视频 |
| `$发送语音 <群号> <语音数据>$` | 发送语音 |
| `$发送音乐卡片 <群号> <类型> <标题> <描述> <链接>$` | 发送音乐卡片 |

## 查询

| 函数 | 说明 |
| --- | --- |
| `$群列表$` | 获取群列表 |
| `$获取好友列表$` | 获取好友列表 |
| `$获取群信息 <群号>$` | 获取群信息 |
| `$获取群成员信息 <群号> <QQ号>$` | 获取单个群成员信息 |
| `$获取群成员列表 <群号>$` | 获取群成员列表 |
| `$获取消息详情 <消息ID>$` | 获取消息详情 |

## 群管理

| 函数 | 说明 |
| --- | --- |
| `$禁言 <群号> <QQ号> <秒数>$` | 禁言群成员 |
| `$全体禁言 <群号>$` / `$全体解禁 <群号>$` | 开启 / 解除全体禁言 |
| `$设置群头衔 <群号> <QQ号> <头衔>$` | 设置群头衔 |
| `$设置群管理 <群号> <QQ号>$` / `$取消群管理 <群号> <QQ号>$` | 设置 / 取消群管理 |
| `$设置群名 <群号> <群名>$` | 修改群名 |
| `$设置群成员名字 <群号> <QQ号> <昵称>$` | 设置群成员昵称 |
| `$踢 <群号> <QQ号>$` | 踢出群成员 |

## 互动

| 函数 | 说明 |
| --- | --- |
| `$点赞 <QQ号> <次数>$` | 点赞 |
| `$戳一戳 <QQ号> <群号>$` | 戳一戳 |
| `$撤回 <消息ID>$` | 撤回消息 |

## 聊天记录（合并转发）

| 函数 | 说明 |
| --- | --- |
| `$构造聊天记录 <名称> <内容>$` | 存入一条记录，返回序号 |
| `$发送聊天记录 <群号> <时间戳> <序号>...$` | 发送合并转发，返回 `resId\|fileName` |
