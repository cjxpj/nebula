# 飞书机器人

飞书机器人通过飞书开放平台的「事件订阅」把群聊 / 单聊消息推送到本框架的 HTTP 接口，由词库处理后回复。

## 接入配置

在 `private/system/config.yaml` 的「飞书」节中配置：

```yaml
飞书:
  启用: true
  词库: private/bot/feishu
  访问路径: feishu-bot
  APPID: cli_xxx
  密钥: xxx
  # 事件订阅的加密密钥（Encrypt Key），留空表示事件未加密
  加密密钥: ""
  # 事件订阅的验证令牌（Verification Token），留空表示不校验
  验证令牌: ""
```

> 「加密密钥」「验证令牌」只能在配置文件中手动填写，管理面板不提供这两项。
> 若在飞书后台开启了事件加密，必须填写「加密密钥」，否则事件无法解密；填写「验证令牌」后框架会校验事件来源。

首次启用时会自动生成词库目录：

```
private/bot/feishu/
  dic/dic.n      # 默认词库模板（FeiShuBot.n）
  admin.txt      # 管理员 open_id 列表，用`,`分割
```

飞书后台需要把「事件订阅」的请求地址填写为 `http(s)://你的域名/<访问路径>`，并订阅「接收消息」事件。群聊还需开启「接收群聊中@机器人消息事件」权限。

## 可用变量

| 变量 | 说明 |
| --- | --- |
| `%QQ%` | 发送者的 open_id（`ou_` 开头） |
| `%群号%` | 群聊为群的 chat_id（`oc_` 开头），私聊为 `0` |
| `%MsgId%` / `%MessageID%` | 当前消息 ID |
| `%主人%` | 管理员时为其 open_id，否则为 `null` |
| `%来源%` | `群聊` 或 `私聊` |

## 飞书函数

使用 `$引入 @FeiShu$` 后可用：

```
// 消息发送
$群单发 <群ID> <文本>$
$私聊 <用户open_id> <文本>$
$回复 <消息ID> <文本>$
$上传图片 <图片数据>$              // 上传图片，返回 image_key
$发送图片 <群ID> <image_key>$
$私聊图片 <用户open_id> <image_key>$

// 查询
$获取群信息 <群ID>$
$获取群成员列表 <群ID>$
$图片 <消息ID> <file_key>$        // 获取图片消息的原始内容（二进制）

// 互动
$撤回 <消息ID>$
$表情回复 <消息ID> <emoji_type>$   // emoji_type 如 THUMBSUP、OK，返回 reaction ID
```

`<图片数据>` 支持 http(s) 链接、`data:` 开头的 Data URL、纯 base64 以及本地文件路径。

> 词库正文直接输出的文本会自动作为回复发送（群聊回到群、私聊回到本人），一般无需调用 `群单发` / `私聊`；
> 这两个函数用于**主动补发**到其他会话。`回复` 则用于对指定消息发起引用回复。
