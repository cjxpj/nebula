## QQ官方机器人 函数

**账号序号说明**：多账号时，主动发送函数的第一个参数为账号序号（`0`=第一个启用的账号，`1`=第二个，以此类推），单账号填 `0`。

**消息变量**（Bot 消息回调时自动注入）

| 变量 | 说明 |
| ---- | ---- |
| `%来源%` | 来源类型（群聊/频道等） |
| `%群号%` | 当前群 OpenID |
| `%QQ%` / `%qq%` | 发言者 QQ（大小写不敏感） |
| `%昵称%` | 发言者昵称 |
| `%管理%` | 群内角色：`1`=群主(owner), `2`=管理员(admin), `0`=普通成员 |
| `%主人%` | admin.txt 中匹配的 QQ 号，不在列表返回 `null` |
| `%robot%` / `%Robot%` / `%robot_appid%` | 机器人 union_openid（需特殊申请，取不到时回退到配置的 Robot 变量值）/ AppID |
| `%头像%` | `http://q.qlogo.cn/qqapp/{AppID}/{QQ}/640` |
| `%MsgId%` / `%msgid%` / `%消息ID%` / `%消息id%` | 当前消息 ID（可用于 `撤回`、引用回复 `±atMsg=%消息ID%±`） |

**群事件变量**（入群/退群/入群申请等事件回调时注入，非普通消息）

| 变量 | 说明 |
| ---- | ---- |
| `%来源%` | 来源描述：`群成员加入` / `群成员退出` / `机器人进群` / `机器人退群` / 入群申请 / 按钮 / 快捷菜单 / `好友添加` / `好友删除` / `机器人上线` |
| `%事件类型%` | `机器人` / `成员`（仅入群/退群事件有值） |
| `%功能ID%` | 快捷菜单功能 ID（仅快捷菜单回调事件有值，管理端设置） |
| `%群号%` | 当前群 OpenID（好友事件无群号） |
| `%成员%` | 加入/退出事件的成员 OpenID（入群申请/好友事件无） |
| `%操作者%` | 操作者 OpenID（机器人进群为邀请者、退群为踢出者；普通成员进群/退群事件无此字段，为空） |
| `%QQ%` / `%qq%` | 成员/好友 QQ OpenID（成员事件取 `member_openid`；机器人事件取操作者 `op_member_openid`；好友事件为好友 OpenID） |
| `%头像%` | 成员/好友头像 `http://q.qlogo.cn/qqapp/{AppID}/{QQ}/640` |
| `%昵称%` | 入群申请人的昵称（仅入群申请事件） |
| `%申请理由%` | 验证消息内容（仅验证消息模式有值，仅入群申请事件） |
| `%申请问题%` | 问答内容，格式 `问题:答案` 以 `;` 分隔（仅问答模式有值，仅入群申请事件） |
| `%申请时间%` / `%申请来源%` | 入群申请时间 / 来源（仅入群申请事件） |
| `%申请ID%` | 入群申请 ID（用于 `入群审批` 主动审批，仅入群申请事件） |
| `%robot%` / `%Robot%` / `%robot_appid%` | 机器人 union_openid（需特殊申请，取不到时回退到配置的 Robot 变量值）/ AppID |

> 事件触发词：进群 `[群事件]群成员进群`、退群 `[群事件]群成员退群`、机器人进群 `[群事件]机器人进群`、机器人退群 `[群事件]机器人退群`、入群申请 `[群事件]入群申请`、好友添加 `[内部]好友添加`、好友删除 `[内部]好友删除`、按钮回调 `[按钮事件]<data>`、快捷菜单回调 `[菜单事件]<功能ID>`、机器人上线 `[系统]启动`，可直接在词库中监听。
> 机器人进群的回复在群内发送（官方支持 event_id 被动回复），机器人退群的回复以私信发给踢出者；好友添加/删除的回复以私信发给该好友。
> 群成员进群走 event_id 被动回复（回复在群内发送）；群成员退群、入群申请为主动推送事件，回复走主动消息，需群主开启【机器人主动在群聊内发言】后才能成功发送到群内。
> 快捷菜单（自定义菜单）仅单聊场景，回调回复以私信形式发送给点击用户，触发词为管理端配置的功能 ID。

**词库示例**：

```
[群事件]群成员进群
欢迎 %成员% 加入本群！

[群事件]群成员退群
%成员% 离开了本群

[群事件]机器人进群
我被 %操作者% 拉进群了

[群事件]入群申请
$发送MD "收到 %昵称%（%QQ%）的入群申请" 按钮 #同意 #拒绝$

// 回调按钮（type=1）点击后触发 [按钮事件]<data>（# 前缀会被剥离），无空格标签无需引号
[按钮事件]同意
已收到同意处理

// 快捷菜单（自定义菜单）回调（type=12）点击后触发 [菜单事件]<功能ID>
[菜单事件]帮助
你好，%QQ%！这里是帮助菜单
```

**获取/搜索账号**（需 `#引入=@QQBot`）

```
$获取账号$              // 返回全部账号 JSON 数组 [{name,appid,path}...]
$获取账号 <序号>$       // 返回指定序号账号 JSON，不存在返回 null
$搜索账号 <关键词>$     // 模糊搜索 remark/名称/appid，返回匹配的账号列表 [{name,appid,path,remark}...]
```

**主动发送（通过 `#引入=@QQBot` 注入，无需消息上下文，URL 访问也可用）**

```
$群单发 <appid> <群OpenID> <文本>$
$群单发图 <appid> <群OpenID> <图片数据> <文本>$
$群单发MD <appid> <群OpenID> <Markdown内容> <键盘JSON(可选)>$
$群单发语音 <appid> <群OpenID> <语音数据>$
$群单发视频 <appid> <群OpenID> <视频数据>$
$私聊 <appid> <用户OpenID> <文本>$
$私聊图 <appid> <用户OpenID> <图片数据> <文本>$
$私聊MD <appid> <用户OpenID> <Markdown内容> <键盘JSON(可选)>$
$禁 <appid> <群OpenID> <成员OpenID> <禁言秒数>$      // 0 表示解禁
$群信息 <appid> <群OpenID>$                          // 返回群信息 JSON
$入群审批 <appid> <群OpenID> <成员OpenID> <op> <申请ID(可选)> <拒绝理由(可选)>$  // op: 同意 / 拒绝 / 拉黑拒绝
$撤回 <appid> <群OpenID> <消息ID>$                    // 撤回群消息（机器人消息 2 分钟内）
$撤回私聊 <appid> <用户OpenID> <消息ID>$              // 撤回单聊消息（机器人消息 2 分钟内）
```

> 主动发送使用全局 Bot API，msgID 为空（非回复模式）。**参数含空格**时文本可用 `"..."` 包裹，如 `$群单发 0 "群OpenID" "这是一条 带空格 的消息"$`。

**菜单 / 指令面板（Bot 消息触发时自动注入，无需 `#引入=`，管理自定义菜单与指令面板）**

```
$获取菜单$                              // 查询当前机器人的全局自定义菜单，返回 JSON {version,menu}
$设置菜单 <菜单JSON>$                    // 修改当前机器人的全局自定义菜单，菜单JSON可为 items 数组或 {items:[...]} 对象
$面板列表 <scope> <游标(可选)> <每页条数(可选)>$   // scope: c2c/group/channel/dm
$创建面板 <创建JSON>$                    // 创建指令面板，创建JSON 为完整 CreatePanelRequest
$面板详情 <面板ID>$                      // 查询指令面板详情，返回 JSON
$修改面板 <面板ID> <面板JSON>$            // 修改面板，面板JSON 可为 items 数组或 {items:[...],remark,version}
$删除面板 <面板ID>$                      // 删除指令面板
$面板关联 <面板ID> <op> <关联JSON>$        // 修改面板关联对象，op: 添加/删除（或 add/del）
```

> 自定义菜单仅 C2C（单聊）场景生效，菜单项 `type` 支持 `switch` / `send_message` / `link` / `menu`（子菜单仅 `send_message` / `link`）；指令面板 `scope` 支持 `c2c` / `group` / `channel` / `dm`，元素 `type` 支持 `command` / `link`；关联 JSON 形如 `{"user_openids":[...]}` 或 `{"group_openids":[...]}`。
> **菜单不是写在 `Main` 触发词里的**：菜单由管理端配置（`$设置菜单$` 下发菜单 JSON），用户点击菜单项后框架以菜单项功能 ID 为触发词唤醒词库——词库侧只需写 `[菜单事件]<功能ID>` 词条处理点击即可（如 `[菜单事件]帮助`）。
> 菜单 JSON 示例：`$设置菜单 [{"type":"switch","name":"自动回复","switch":{"switch_id":"auto_reply","default":true}},{"type":"menu","name":"帮助","sub_menu_items":[{"type":"send_message","name":"使用说明","send_message":"发送'帮助'查看说明"}]}]$`

**回复发送（依赖 PushContext，Bot 消息处理时由框架自动注入，无需 `#引入=`）**

```
$发送文本 <文本> <图片数据>$
$发送MD <Markdown内容> <按钮 [样式数字]标签[|数据] ...>$
$发送MD <模板ID> <键1> <值1>...$
$发送视频 <视频数据>$
$发送语音 <语音数据>$
$流式发送 <内容> <状态(可选)> <stream_msg_id(可选)> <index(可选)> <内容类型(可选)>$
$禁 <群OpenID> <成员OpenID> <禁言秒数>$     // 不传群号则取当前群；0 表示解禁
$踢 <群OpenID> <成员OpenID>$                // 移除群成员（踢出群）
$踢黑 <群OpenID> <成员OpenID>$              // 移除群成员并加入群黑名单
$获取群信息 <群OpenID>$                   // 参数留空则取当前群号，返回群信息 JSON
$获取机器人群内状态 <群OpenID>$            // 参数留空则取当前群号，返回机器人群内状态 JSON
$入群审批 <群OpenID> <成员OpenID> <op> <申请ID(可选)> <拒绝理由(可选)>$   // op: 同意 / 拒绝 / 拉黑拒绝，群号必填
$撤回 <消息ID>$                              // 撤回当前群消息（机器人消息 2 分钟内）
$撤回 <群OpenID> <消息ID>$                   // 撤回指定群消息
$撤回私聊 <消息ID>$                          // 撤回当前单聊消息
$撤回私聊 <用户OpenID> <消息ID>$             // 撤回指定单聊消息
```

> 回复函数使用当前消息上下文（群OpenID、MsgID），仅在 QQBot 消息回调触发的词库中可用。**词库正文直接输出的文本会自动作为回复发送，一般无需调用这些函数**（触发词下的文本行、`文本>` 块、`%变量%` 拼接等内容执行完由框架统一回复）；回复函数只在需要**主动补发额外消息**或带图/带按钮（`发送文本` 第二参数图片数据、`发送MD` 按钮）时使用。
> `发送MD` 群聊/私聊用法一致：单参数为 MD 文本直接发送；多参数为 `模板ID 键1 值1...`，键值必须成对，不成对会报错"要设置对应键跟值"。
> `流式发送` 仅单聊（C2C）可用，用于流式分批发送 Markdown/文本：`状态` 为 `1`（生成中）或 `10`（生成结束，默认）；`stream_msg_id` 首片留空、续片传入上一片返回的 id；`index` 从 0 递增（默认 0）；`内容类型` 为 `text` / `markdown`（默认 markdown）。函数返回首片生成的 stream_msg_id。

**入群申请处理**

通过 `入群审批` 同意或拒绝入群申请：

```
// ReplyFuncs 形式（%群号% 群OpenID，%QQ% 为申请人 OpenID，%申请ID% 为审批令牌）
$入群审批 %群号% %QQ% 同意 %申请ID%$
$入群审批 %群号% %QQ% 拒绝 %申请ID% 不符合入群条件$
$入群审批 %群号% %QQ% 拉黑拒绝 %申请ID% 不符合入群条件$

// ActiveFuncs 形式（需 #引入=@QQBot，首参数为账号序号）
$入群审批 1 %群号% %QQ% 同意 %申请ID%$
$入群审批 1 %群号% %QQ% 拒绝 %申请ID% 不符合入群条件$
$入群审批 1 %群号% %QQ% 拉黑拒绝 %申请ID% 不符合入群条件$
```

> 触发词为 `[群事件]入群申请`，回调时自动注入 `%群号%`、`%QQ%`（申请人 OpenID）、`%昵称%`、`%申请理由%`、`%申请问题%`、`%申请时间%`、`%申请来源%`、`%申请ID%` 等变量，可直接与 `入群审批` 搭配使用。

**消息按钮（Keyboard）**

`发送MD` 通过 `按钮` 关键字分隔按钮定义，按钮使用参数串格式传递。第二参数为 JSON（`{"rows":[...]}` 或 `{"id":"..."}`）时自动解析为键盘。自定义按钮仅支持简单文本模式（`$发送MD <Markdown内容> 按钮 ...$`）；模板模式（`$发送MD <模板ID> <键1> <值1>...`）不支持自定义按钮，仅插入文本，键/值可正常使用"按钮"字样：

```
// [样式数字]标签[|数据]（\r 后缀换行；样式 [0]~[3]，默认 [0]）
$发送MD "# 标题\n内容" 按钮 [1]确认|/确认 [0]取消|/取消\r$

// 简写：标签|数据，自动推断类型
$发送MD "# 菜单" 按钮 查看详情|https://example.com 确认|#回调操作$
// → "查看详情" 外显为链接网址，"确认" 外显为回调按钮 data=回调操作

// data 以 # 开头自动为回调（type=1），触发词格式：[按钮事件]data
$发送MD "# 请确认" 按钮 确认|#确认操作 取消|#取消操作$

// 二次确认弹窗：#[取消文案|确认文案]提示，点击回调按钮先弹窗，[] 后的文本同时作为按钮文字、回调 data 和弹窗提示
$发送MD "# 危险操作" 按钮 #[取消|确认]确定执行？\r$

// 模板模式不支持自定义按钮，仅插入文本，"按钮"可正常作为键/值
$发送MD 模板ID key val 按钮 了解更多$
```

按钮 type（由 data 前缀自动推断）：`0`=跳转链接（data 以 http 开头）、`1`=回调（data 以 `#` 开头）、`2`=指令（默认，输入框自动填充 data）；按钮样式（开头 `[数字]`）：`0`=灰色线框（默认）、`1`=蓝色线框；按钮 permission.type：`0`=指定用户、`1`=仅管理者、`2`=所有人

**JSON 键盘**（`发送MD` 第2参数 与 `群单发MD` 第4参数均支持）：

```
$发送MD "# 标题" {"rows":[{"buttons":[{"id":"1","render_data":{"label":"确认","visited_label":"已确认","style":1},"action":{"type":2,"permission":{"type":2},"data":"/确认","enter":true}}]}]}$
$群单发MD 1 群OpenID "# 标题" {"rows":[{"buttons":[{"id":"1","render_data":{"label":"确认","visited_label":"已确认","style":1},"action":{"type":2,"permission":{"type":2},"data":"/确认","enter":true}}]}]}$
$群单发MD 1 群OpenID "# 标题" {"id":"123456"}$
```

**按钮回调事件**

action.type=1（回调按钮）点击后触发 `INTERACTION_CREATE` 事件，框架自动回应并转为词库消息处理。触发词格式为 `[按钮事件]<data>`（`/` 前缀会被剥离），支持 `%QQ%（点击者）` / `%群号%` / `%来源%（=按钮）` 等事件变量。可通过 `$设置状态 <状态码>$` 控制按钮交互的返回结果：`0`=成功（默认）、`1`=操作失败、`2`=操作频繁、`3`=重复操作、`4`=没有权限、`5`=仅管理员操作。

```
// 发送带回调按钮的 MD（标签|#数据），data 中 / 前缀会被剥离
$发送MD "# 请确认操作" 按钮 确认|#确认操作 取消|#取消操作$

// 监听按钮回调并通过 $设置状态 改变返回结果
[按钮事件]确认操作
$设置状态 4$
你没有权限执行此操作
```
