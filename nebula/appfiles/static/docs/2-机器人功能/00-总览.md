# 机器人功能

> **使用机器人函数前，需在词库头部添加对应的引入指令**（如 `$引入 @QQBot$`、`$引入 @NapCat$`、`$引入 @FeiShu$`，引入后框架会自动注入该机器人的回复函数与主动发送函数）。

各平台单独成篇：

- QQ官方机器人（docs/2-机器人功能/01-QQ官方机器人.md）：官方 QQBot，回复/主动发送、菜单与指令面板、按钮、入群审批、频道。
- NapCat（docs/2-机器人功能/02-NapCat.md）：NapCat 接入的消息发送、查询、群管理与互动函数。
- 飞书机器人（docs/2-机器人功能/03-飞书机器人.md）：飞书事件订阅接入、群聊/私聊处理、消息发送、图片上传与群信息查询函数。
- SecludedBot 插件协议（docs/2-机器人功能/04-SecludedBot插件协议.md）：Secluded 插件协议的配置、变量、事件、消息语法与内置函数。
