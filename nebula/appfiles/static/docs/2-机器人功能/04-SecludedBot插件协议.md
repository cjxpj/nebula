# SecludedBot 插件协议

## 配置说明

在 `NebulaData/private/system/config.yaml` 中配置：

```yaml
Secluded:
  启用: true
  词库: private/bot/secluded
  对接地址: ws://127.0.0.1:24804
  令牌: SecretToken
```

| 配置项 | 说明 | 默认值 |
| ---- | ---- | ---- |
| 启用 | 是否启用 Secluded 插件 | false |
| 词库 | 词库目录路径 | private/bot/secluded |
| 对接地址 | WebSocket 服务地址 | ws://127.0.0.1:8080 |
| 令牌 | 认证令牌 | 空 |

## 词库变量

| 变量 | 说明 |
| ---- | ---- |
| `%来源%` | 来源类型（群聊/私聊/临时） |
| `%群号%` | 目标群号 |
| `%QQ%` / `%qq%` | 发言者 QQ（大小写不敏感） |
| `%昵称%` | 发言者昵称 |
| `%管理%` | 发言者管理权限：`1`=群主/创建者, `2`=管理员, `0`=普通成员 |
| `%主人%` | 主人列表（admin.txt）中匹配的 QQ 号，不在列表返回 `null` |
| `%MsgId%` | 消息 ID |
| `%robot%` | 机器人账号 |
| `%data%` | 消息完整原始数据 JSON；`[系统]推送` 事件中为推送 Json 数据 |

## 事件触发

支持以下事件触发词，可直接在词库中监听：

| 触发词 | 说明 |
| ---- | ---- |
| `[系统]启动` | 插件连接成功时触发（每次客户端重启后触发一次） |
| `[系统]推送` | 收到系统即时推送时触发（System=System 且 InstantPush=InstantPush），`%data%` 为推送 Json 数据 |
| `[内部]断开连接` | 插件断开连接时触发 |
| `[群事件]全体禁言开启` | 群开启全体禁言时触发 |
| `[群事件]全体禁言关闭` | 群关闭全体禁言时触发 |
| `[群事件]成员禁言 0` | 成员被解禁时触发 |
| `[群事件]成员禁言 [0-9]+` | 成员被禁言时触发，`%参数1%` 为禁言秒数 |

> 全体禁言事件可用 `%群号%`；成员禁言/解禁事件可用 `%QQ%`（被操作成员）、`%Op%`（操作者）、`%参数1%`（禁言秒数）。

## 消息语法

支持的消息语法（与 NapCat 一致）：

| 语法 | 功能 | 示例 |
| ---- | ---- | ---- |
| `±at=QQ号±` | @ 指定用户 | `±at=%QQ%± 你好！` |
| `±img=<图片数据>±` | 发送图片 | `±img=https://example.com/pic.png±` |
| `±atMsg=消息ID±` | 引用回复 | `±atMsg=%MsgId%± 收到！` |

> `±img=<图片数据>±` 是**机器人场景**下发送图片的消息语法，**不是**给图片变量赋值；`<图片数据>` 可为图片 URL、`data:` 数据 URL 或本地文件路径（如 `±img=database/img.png±`）。变量赋值统一用 `键:值`（半角冒号），与 `±...±` 消息标记无关。

## 内置函数

### 消息发送

**群单发** 发送群消息

```
$群单发 <群号> <文本>$
// 示例
群单发 (.+)
$群单发 %群号% %括号1%$
```

**私聊** 发送私聊消息

```
$私聊 <QQ号> <文本>$
// 示例
私聊 (.+)
$私聊 %QQ% %括号1%$
```

**发送语音** 发送群语音消息

```
$发送语音 <群号> <语音直链> <外显时长秒>$
// 示例
$发送语音 %群号% https://example.com/voice.amr 5$
```

**发送视频** 发送群视频消息（可选封面）

```
$发送视频 <群号> <视频直链> <外显时长秒> <封面直链>$
// 示例
$发送视频 %群号% https://example.com/video.mp4 30 https://example.com/cover.jpg$
```

**撤回** 撤回群消息

```
$撤回 <群号> <消息ID>$
// 示例
$撤回 %群号% %MsgId%$
```

**灰色消息** 发送灰色提示消息（可能已不灵）

```
$灰色消息 <群号> <文本>$
```

**Xml卡片** 发送 XML 卡片消息（只能和群号并存）

```
$Xml卡片 <群号> <Xml内容>$
```

**Json卡片** 发送 JSON 卡片消息（只能和群号并存）

```
$Json卡片 <群号> <Json内容>$
```

### 群管理

**禁** 禁言群成员，不填 QQ 号则为全体禁言，时间填 0 为解禁

```
$禁 <群号> <QQ号> <禁言秒数>$
// 示例
$禁 %群号% 60$
$禁 %群号% 123456789 300$
$禁 %群号% 123456789 0$
```

**全体禁言** 单独全体禁言整个群

```
$全体禁言 <群号>$
```

**全体解禁** 解除整个群的全体禁言

```
$全体解禁 <群号>$
```

**踢** 踢出群成员

```
$踢 <群号> <QQ号>$
// 示例
$踢 %群号% 123456789$
```

**邀请加群** 邀请用户加入群聊

```
$邀请加群 <群号> <QQ号>$
```

**修改群名** 修改群名称

```
$修改群名 <群号> <新群名>$
// 示例
$修改群名 %群号% 新的群名称$
```

**创建群聊** 创建新的群聊，返回创建结果 JSON

```
$创建群聊 <群名>$
// 示例
$创建群聊 测试群$
```

**管理员变动** 添加或取消群管理员；操作支持 `add`/`添加`（添加）、`del`/`删除`（取消）

```
$管理员变动 <群号> <QQ号> <操作>$
// 示例
$管理员变动 %群号% 123456789 添加$
$管理员变动 %群号% 123456789 del$
```

**拍一拍** 群聊拍一拍（双击头像）

```
$拍一拍 <群号> <QQ号>$
// 示例
$拍一拍 %群号% %QQ%$
```

**群打卡** 群打卡

```
$群打卡 <群号>$
```

**群通知处理** 处理群入群申请（同意/拒绝）；操作支持 `yes`/`同意`/`通过`（同意）、`no`/`拒绝`（拒绝可附理由）

```
$群通知处理 <群号> <申请MsgId> <Code> <操作> <拒绝理由>$
// 示例
$群通知处理 %群号% %MsgId% %Code% yes$
$群通知处理 %群号% %MsgId% %Code% 拒绝 不符合入群条件$
```

**群待办** 添加或删除群待办；操作支持 `add`/`添加`、`del`/`删除`

```
$群待办 <群号> <消息ID> <操作>$
// 示例
$群待办 %群号% %MsgId% 添加$
```

**设置消息接收模式** 设置群聊消息接收模式；`1`=关闭消息免打扰，`2`=收进群助手且不提醒，`3`=屏蔽群消息，`4`=接收消息但不提醒

```
$设置消息接收模式 <群号> <模式数字>$
// 示例
$设置消息接收模式 %群号% 1$
```

**加群** 机器人加入指定群聊，可附带加群验证信息

```
$加群 <群号> <验证信息>$
// 示例
$加群 123456789$
$加群 123456789 我是机器人$
```

**添加群白名单** 将群号加入白名单

```
$添加群白名单 <群号>$
```

**删除群白名单** 将群号移出白名单

```
$删除群白名单 <群号>$
```

### 好友操作

**添加好友** 添加好友，可选验证信息

```
$添加好友 <QQ号> <验证信息>$
// 示例
$添加好友 123456789$
$添加好友 123456789 你好，我是机器人$
```

**删除好友** 删除好友

```
$删除好友 <QQ号>$
```

**设置好友备注** 设置好友备注名

```
$设置好友备注 <QQ号> <备注名>$
// 示例
$设置好友备注 123456789 小明$
```

### 查询列表

**获取群列表** 获取机器人所在的群列表（等待响应超时 10 秒）

```
$获取群列表$
```

**启动获取群列表** 获取启动时自动缓存好的群列表（无需等待响应）

```
$启动获取群列表$
```

**获取好友列表** 获取机器人的好友列表（等待响应超时 10 秒）

```
$获取好友列表$
```

**获取群成员列表** 获取指定群的成员列表（等待响应超时 10 秒）

```
$获取群成员列表 <群号>$
```

**获取不活跃列表** 获取指定群的不活跃成员列表（等待响应超时 10 秒）

```
$获取不活跃列表 <群号>$
```

**获取用户信息** 获取机器人账号基本信息及 Cookie（需开启安全密钥）

```
$获取用户信息$
```

**贴表情** 发送表情回复（贴表情到指定消息）

```
$贴表情 <群号> <消息ID> <表情数据>$
// 示例
$贴表情 %群号% %MsgId% 1$
```

### 其他功能

**空间点赞** QQ 空间点赞

```
$空间点赞 <QQ号> <空间消息ID>$
// 示例
$空间点赞 123456789 %MsgId%$
```

**点赞** 点赞卡片（FavoriteCard）

```
$点赞 <Uin> <Uid> <Value>$
```

**SEC打印（日志）** 向控制台输出日志；级别：`s`/`success`（绿色）、`i`/`info`（蓝色）、`d`/`debug`（灰色）、`w`/`warning`（黄色）、`e`/`error`（红色）

```
$SEC打印 <级别> <内容>$
// 示例
$SEC打印 i 收到消息已处理
$SEC打印 d 调试信息：QQ=%QQ%$
```

**SEC发包（高级）** 自定义发包，直接发送原始 JSON 数据包，支持所有消息标签

```
$SEC发包 <JSON数据> <指定账号>$
// 示例
$SEC发包 [{"Group":"Group","GroupId":"%群号%"},{"Text":"你好"},{"Img":"https://example.com/pic.png"}]$
$SEC发包 [{"Group":"Group","GroupId":"%群号%","MsgId":"%MsgId%","EmoReply":"1"}]$
```

第二个参数可指定发送账号，留空使用当前机器人账号。JSON 数据格式为 `[]map[string]string` 数组，支持文档中所有消息标签（Text、Img、Ptt、Video、AtUin、Reply 等）。
