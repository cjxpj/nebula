# 定时任务

> 支持用函数添加 / 删除 / 获取定时词库任务列表，每个任务有唯一编号，添加时返回编号；任务按指定间隔执行指定词库的触发词，持久化到全局数据库（database/data.db 的 scheduled_tasks 表），重启后自动恢复调度。

## 添加定时任务

> 参数：时间、触发词（可选，默认 Main）、词库路径（可选，默认当前词库）、一次性（可选，默认循环）、启动触发一次（可选，默认关闭），返回唯一编号；时间支持数字（毫秒）、s / m / h / d、整点、整分
> 一次性传入 true / 1 表示执行一次后自动删除，否则循环执行；启动触发一次传入 true / 1 表示添加后立即触发一次，之后仍按间隔循环执行

```
编号:$添加定时任务 5000 Main private/task.n$
当前词库:$添加定时任务 5000$
一次:$添加定时任务 整点 Main private/task.n true$
启动即触发:$添加定时任务 5000 Main private/task.n false true$
```

## 删除定时任务

```
$删除定时任务 <编号>$
```

## 定时任务列表

```
$定时任务列表$   // 返回 JSON 数组，每项含 id / dic_path / trigger / interval / once / run_at_start
```
