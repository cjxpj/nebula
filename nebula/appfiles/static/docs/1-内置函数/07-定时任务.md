# 定时任务

支持用函数添加 / 删除 / 获取定时词库任务列表，每个任务有唯一编号，添加时返回编号；任务按指定间隔执行指定词库的触发词，持久化到全局数据库（`database/data.db` 的 `scheduled_tasks` 表），重启后自动恢复调度。

## 添加定时任务

`$添加定时任务 时间 [触发词] [词库路径] [一次性] [启动触发一次] [异步执行]$`，返回唯一编号。

| 参数 | 默认 | 说明 |
| ---- | ---- | ---- |
| 时间 | 必填 | 数字（毫秒）、`s` / `m` / `h` / `d`、整点、整分 |
| 触发词 | `Main` | 执行词库里的哪个触发词 |
| 词库路径 | 当前词库 | |
| 一次性 | 循环 | 传 true / 1 表示执行一次后自动删除 |
| 启动触发一次 | 关闭 | 传 true / 1 表示添加后立即触发一次，之后仍按间隔循环执行 |
| 异步执行 | 开启 | 传 true / 1 表示在独立协程中执行、不阻塞计时（默认，适合间隔较短的任务，如 1 分钟）；传 false / 0 表示同步执行，本次执行完成后才开始下一轮计时 |

```
编号:$添加定时任务 5000 Main private/task.n$          // 每 5 秒执行 private/task.n 的 Main
当前词库:$添加定时任务 5000$                          // 词库路径省略 = 当前词库
一次:$添加定时任务 整点 Main private/task.n true$      // 整点执行一次后自动删除
启动即触发:$添加定时任务 5000 Main private/task.n false true$
同步执行:$添加定时任务 5000 Main private/task.n false false false$
```

## 删除定时任务

```
$删除定时任务 <编号>$
```

## 定时任务列表

```
$定时任务列表$   // 返回 JSON 数组，每项含 id / dic_path / trigger / interval / once / run_at_start / async
```
