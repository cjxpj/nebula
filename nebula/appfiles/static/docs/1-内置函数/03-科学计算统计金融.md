# 科学计算 / 统计 / 金融

> 三角函数输入为**弧度**；结果返回浮点数。非法输入（如 `$平方根 -1$`、`$反正弦 2$`）返回 `NaN` 或 `Inf`。不要把角度（度）直接传给三角函数——`$sin 30$` 算的是 30 **弧度**（≈1718.9°）的正弦 ≈ -0.988，而非 `sin 30° = 0.5`，需先用「角度转弧度」转成弧度（见下）。

## 三角函数 / 反三角函数

```
$正弦 <弧度>$
$sin 1$
$余弦 1.5708$       // cos(π/2) ≈ 0
$正切 0.785$        // tan(π/4) ≈ 1
$反正弦 1$          // asin(1) = π/2
$反余弦 0$
$反正切 1$
$反正切2 <y> <x>$   // atan2(y,x)，可区分象限
```

## 角度单位转换

> 三角函数入参是弧度；测绘常用**角度（度）、百分度（gon）、密位（NATO mil）**，先转弧度再计算。

```
$角度转弧度 30$        // 0.5235987755982988（= 30 * π/180）
$deg2rad 30$
$弧度转角度 0.5235987755982988$   // 30
$rad2deg 1.5707963267948966$      // 90

$百分度转弧度 100$    // π/2（直角 = 100 gon）
$弧度转百分度 1.5707963267948966$ // 100

$密位转弧度 1600$     // π/2（直角 = 1600 mil）
$弧度转密位 1.5707963267948966$   // 1600
```

用法：先转弧度存变量，再算三角函数。

```
弧度:$角度转弧度 30$
$sin %弧度%$          // 0.5
```

## 角度制三角函数

> 直接传入角度（度/百分度/密位），内部自动转弧度，调用意图更清晰，避免漏转。

```
$正弦度 30$ / $SinDeg 30$        // 0.5
$余弦度 60$ / $CosDeg 60$        // 0.5
$正切度 45$ / $TanDeg 45$        // 1

$正弦百分度 100$ / $SinGon 100$  // 1（直角 = 100 gon）
$余弦百分度 200$                 // -1
$TanGon 50$                      // 1

$正弦密位 1600$ / $SinMil 1600$  // 1（直角 = 1600 mil）
$余弦密位 3200$                  // -1
$TanMil 800$                     // 1
```

## 指数 / 对数 / 取整

```
$幂运算 <底数> <指数>$ / $pow 2 10$          // 1024
$指数 1$ / $exp 1$                           // exp(1) = e
$自然对数 2.718281828$ / $log 1$ / $ln 1$    // ln(e) ≈ 1
$常用对数 100$ / $log10 100$                 // log10(100) = 2
$二进制对数 8$ / $log2 8$                    // log2(8) = 3
$平方根 2$ / $sqrt 2$                        // sqrt(2)
$立方根 27$ / $cbrt 27$                      // 3
$绝对值 -5$ / $abs -5$                       // 5
$向上取整 3.14$ / $ceil 3.14$                // 4
$向下取整 3.14$ / $floor 3.14$               // 3
```

## 统计

> 统计函数支持两种输入：多个数值参数，或单个 JSON 数组 `[1,2,3]`。方差/标准差按**总体**（除以 N）计算。

```
$求和 1 2 3 4$ / $sum [1,2,3,4]$      // 10
$计数 1 2 3$ / $count [1,2,3]$        // 3
$平均值 1 2 3 4$ / $mean [1,2,3,4]$   // 2.5
$中位数 1 3 5 7$                      // 4
$中位数 1 3 5 7 9$                    // 5
$median [1,2,3]$
$方差 1 2 3 4$                        // 1.25
$标准差 1 2 3 4$                      // ≈1.118
```

## 金融

```
$净现值 <折现率> <现金流1> <现金流2> ...$
$NPV 0.1 100 100 100$    // 100/1.1 + 100/1.21 + 100/1.331 ≈ 248.69

$内部收益率 <现金流0> <现金流1> ...$   // 现金流0 通常为初始投入（负数）
$IRR -1000 300 300 300 300$           // 返回 0.0771（即 7.71%）
```

## 复数

> 复数以「实部、虚部」两个数表示，输出为 `a+bi` 文本。

```
$复数加 <a实> <a虚> <b实> <b虚>$
$复数加 1 2 3 4$     // 4+6i
$复数减 3 4 1 2$     // 2+2i
$复数乘 1 2 3 4$     // -5+10i
$复数除 1 0 1 1$     // 0.5-0.5i
$复数模 3 4$         // 5
$复数共轭 3 4$       // 3-4i
```

## 矩阵

> 矩阵用 JSON 二维数组表示，如 `[[1,2],[3,4]]`；运算结果同样返回 JSON 二维数组。维度不匹配或奇异矩阵返回 `[]`。

```
$矩阵加 [[1,2],[3,4]] [[5,6],[7,8]]$      // [[6,8],[10,12]]
$矩阵减 [[5,6],[7,8]] [[1,2],[3,4]]$      // [[4,4],[4,4]]
$矩阵乘 [[1,2],[3,4]] [[5,6],[7,8]]$      // [[19,22],[43,50]]
$矩阵转置 [[1,2,3],[4,5,6]]$              // [[1,4],[2,5],[3,6]]
$矩阵行列式 [[1,2],[3,4]]$                // -2
$矩阵逆 [[4,7],[2,6]]$                    // [[0.6,-0.7],[-0.2,0.4]]
```
