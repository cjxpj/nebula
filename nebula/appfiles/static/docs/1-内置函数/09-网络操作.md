# 网络操作

## 终止服务器

// 直接终止服务器，不会关闭主程序，可以做一些应急措施后查看程序日志

```
$终止服务器$
```

## 访问数据

```
$全局变量 访问数据$
```

GET返回示例

```json
{"路径":"/api.n","来源":"GET",
 "请求头":{"Accept-Encoding":["gzip"],"User-Agent":["Nebula-Client/1.0"]},
 "IP":"127.0.0.1","Host":"127.0.0.1:8080"}
```

> `$GET$` / `$POST$` 读取的是 **HTTP 请求**参数，只有词库作为**网页被 HTTP 访问**时才有值。**机器人词库中不可用**：机器人场景没有 HTTP 请求上下文，`$GET$` / `$POST$` 只会返回默认值，应改用 `%参数N%`（按空格分割的匹配文本）、`%括号N%`（正则捕获组）、`%QQ%` / `%群号%` 等消息上下文变量。

获取GET参数

```
$GET key 默认值$
```

获取POST参数

```
$POST key 默认值$
```

POST返回示例：结构同 GET，仅「来源」为 `POST`。

```

$全局变量 输出头部 {"Location":"https://cjxpj.com"}$

```

## COOKIE

设置后会在输出时候进行。`禁用JS` 默认 false，禁用后无法让 JavaScript 读取，仅限在域名访问中传输；`存活` 默认 0，秒为单位。

```
a:"""
[{"命名":"id","数据":"123456","路径":"/","禁止JS":false,"存活":3600}]
"""
$全局变量 COOKIE %a%$
```

**目录结构**

服务器WS词库
> private/websocket/server.n

客户端WS词库-支持自义定
> private/websocket/app.n

## WS连接

WS连接配合异步使用

```
// 词库路径留空默认 private/websocket/app.n
ws连接数据:$WS连接 <URL> <词库路径>$
// 放在线程变量中储存
$线程变量 WS %ws连接数据%$
```

回复WS消息可用

```
$WS断开连接$
$WS发送 <WS数据> 文本$
$WS断开 <WS数据>$
```

类型变量

```
文本消息
二进制消息
未知消息
```

## 创建WS

创建并监听一个 WebSocket 服务，返回一个「WS 对象」（面对像）。创建时跨域默认开启，可通过对象方法进一步配置。

```
// 词库路径必填，跨域留空默认 true
甲:$创建WS <访问路径> <词库路径> <跨域>$
甲:$创建WS /myws private/websocket/server.n$

// WS 对象方法
$甲.设置跨域 false$                              // 设置是否允许跨域
$甲.设置词库路径 private/websocket/server.n$     // 设置处理连接的词库路径
$甲.设置访问路径 /myws2$                         // 设置访问路径
$甲.设置变量 键 值$                              // 设置对象变量（变量随 WS 一直存在）
```

读取对象变量：`%甲.键%`

## 创建服务器

创建一个独立的 HTTP 词库服务器。每个请求以 **URL 路径作为触发词**运行词库，输出作为 HTTP 响应。返回「服务器对象」（面对像）。

> 创建后**不会立即启动**，需调用 `$甲.启动$` 后才开始监听端口。
> **第二参数接受编译好的词库数据**（gob 字节编译产物，或直接把 `$编译词库$` 返回的 map 传入自动取「编译数据」），不是源码文本、也不是文件路径；可留空，留空后先用「设置路由词库」补齐再启动。编译产物可由 `//@资源 变量:xxx.n` 自动编译得到，或用 `$编译词库$` 编译后取「编译数据」。可在启动词库 `start.n` 中调用本函数，实现程序启动时自动创建独立服务器。
> **核心服务器**：多台服务器中会标记一台为核心，用于承载管理面板（OPUI）、防火墙、云工具、机器人 webhook、WebSocket 服务等内置入口，其余服务器仅跑词库路由。核心身份**不会自动指定**（第一个创建的服务器也不默认核心），须启动后调用 `$甲.设置核心服务器$` 显式标记，标记后其余服务器自动取消核心。核心服务器的 WebUI 地址可用 `$核心服务器$` 获取。
> **BeerFrp 穿透**：可用 `$甲.设置BeerFrp 开关 调试 令牌 服务器地址$` 配置（默认 true / false / 空 / wss://frp.cjxpj.com），或在前端「服务器列表」编辑弹窗中配置，保存后立即建立/断开隧道。

创建服务器

```
// 端口地址可写 8080 或 :8080；词库数据可留空，留空后先用「设置路由词库」补齐再启动
甲:$创建服务器 <端口地址> <编译好的词库数据>$
// 先编译源码（返回 JSON），再把整个 JSON 传给创建服务器（自动取「编译数据」字段）
编译:$编译词库 a$
甲:$创建服务器 8999 %编译%$
```

服务器对象方法

```
// 启动服务器，开始监听端口（端口被占用会报错）
$甲.启动$
// 设置路由词库：支持编译好的词库数据（$编译词库$ 返回值或 //@资源 编译产物）或词库文件路径/源码，内部立即生效
$甲.设置路由词库 <编译好的词库数据 | 词库路径 | 源码>$
// 停止服务器释放端口
$甲.关闭$
// 设置对象变量（变量随服务器一直存在）
$甲.设置变量 键 值$
// 设置是否允许跨域（创建时默认 true）
$甲.设置跨域 false$
// 将当前服务器标记为核心服务器（须先启动），其余自动取消核心
$甲.设置核心服务器$
// 配置 BeerFrp 穿透：开关 / 调试 / 令牌 / 服务器地址
$甲.设置BeerFrp true false 令牌 wss://frp.cjxpj.com$
```

读取对象变量：`%甲.键%`

## 编译词库

把词库源码编译，直接返回 **map 结构数据**（不经 JSON 序列化与 base64 编解码，避免数据错误），含三个键：**编译数据**（原始 gob 字节 `[]byte`）、**报错数据**、**警告数据**（报错/警告为数组，元素含 `line` / `text` / `level`）。

```
编译:$编译词库 <词库数据>$
```

> 「编译数据」可直接传给 `$创建服务器$` 作为第二参数（直接传整个 map，创建服务器自动取「编译数据」字段）。词库含自定义函数（bot 注入）时无法序列化，「编译数据」为空（对应报错）。等价于 `//@资源 变量:xxx.n` 对 `.n` 词库的自动编译结果。

## 核心服务器

返回当前核心服务器的 WebUI 地址（`http://localhost:端口/管理面板路径`）；已生成快捷登录码时自动拼接 `?key=快捷登录码`，供启动词库打印后直接快捷登录；无核心服务器时返回空串。

```
$核心服务器$
```

> 核心服务器由 `$创建服务器$` 体系维护：创建后**不会自动成为核心**，须调用 `$服务器.设置核心服务器$` 显式指定。示例（启动词库打印）：`WebUi: $核心服务器$`。

## 高度自定义访问

`$新建访问$` 返回一个「请求对象」（面对像），后续通过 `$对象.方法$` 链式配置并发送请求。默认 GET、跳转开启、超时 0（不限制）。

```
a:$新建访问 url$

// 切换请求方式
$a.切换GET$
$a.切换POST$            // 或带 body：$a.切换POST body$
$a.切换PUT$             // 或带 body：$a.切换PUT body$
$a.切换DELETE$          // 或带 body：$a.切换DELETE body$
$a.切换PATCH$           // 或带 body：$a.切换PATCH body$
$a.切换HEAD$
$a.切换OPTIONS$

// 请求体与文件
$a.POST data$                   // 设置 POST 表单数据
$a.POST文件 form name data$     // 上传文件（form 和 name 不同名）
$a.POST文件 name data$          // 上传文件（form 和 name 同名）

// 请求配置
$a.设置头部 {"Key":"Value"}$    // 自定义头部（JSON 或字符串）
$a.设置超时 15$                 // 超时，秒为单位，0 为不限制
$a.启用跳转$                    // 跳转控制：默认启用
$a.禁用跳转$                    // 禁用后可拦截 Location 跳转

// 发送与读取
$a.发送$        // 发送请求（不返回数据，需用下方函数取结果）
$a.全部内容$    // 获取全部信息（含请求配置等，会屏蔽响应内容）
$a.内容$        // 仅获取响应内容
```
