# 其他工具

## 主机

> 获取系统运行信息，返回字符串或 JSON。

```
$主机 程序CPU$       // 程序 CPU 使用率（百分比）
$主机 程序内存$      // 程序内存占用（MB）
$主机 CPU$           // 系统 CPU 使用率（带小数）
$主机 CPU百分比$     // 系统 CPU 使用率（取整）
$主机 CPU信息$       // CPU 详细信息 JSON
$主机 内存$          // 内存使用信息 JSON
$主机 内存百分比$    // 内存使用百分比
$主机 磁盘$          // 磁盘分区信息 JSON
$主机 网络$          // 网络接口信息 JSON
```

## 腾讯接口

`$腾讯接口$` 返回「腾讯云 API 对象」（面对像），后续通过 `$对象.调用$` 发起请求：

```
接口:$腾讯接口 <SecretId> <SecretKey> <域名> <服务名> <接口名> <版本> <地域|可留空>$  // 创建接口对象
$接口.调用 {"json":"数据"}$                                                       // 调用，参数为 JSON，返回响应字符串
```

参数：`<域名>` 如 `cvm.tencentcloudapi.com`；`<服务名>` 如 `cvm`；`<接口名>` 如 `DescribeInstances`；`<版本>` 如 `2017-03-12`；`<地域>` 如 `ap-guangzhou`（部分接口可留空）。

## Json字典

`$创建字典$` 返回「有序字典对象」（面对像），保持键的插入顺序并生成 JSON，参数 JSON 可留空。

```
a:$创建字典 <json>$
$a.设置 <键> <值>$                  // 设置值
$a.设置 <层级1> <层级2> <键> <值>    // 多层键值：最后一个参数为值，其余为层级路径
$a.获取$                            // 返回按插入顺序排列的 JSON 字符串
```

示例：

```
a:$创建字典$
$a.设置 name 张三$
$a.设置 info age 18$
$a.获取$    // {"name":"张三","info":{"age":"18"}}
```

## 配置读写

> 读写配置文件，支持 `.ini` 和 `.yaml`/`.yml`，按文件后缀自动选择解析方式。
>
> **文件名简写：** `system` / `config`（以及它们的 `.ini`/`.yaml`/`.yml` 形式）统一指向合并后的 `private/system/config.yaml`；省略扩展名时自动匹配已存在的 `.ini`/`.yml`/`.yaml`（如 `a` 匹配 `a.ini`），都不存在时默认按 `.ini` 创建。其余路径相对于 `NebulaData/`。
>
> **节点格式：** YAML 为嵌套路径，如 `A.B.C` 对应 `A` 下的 `B` 下的 `C`；INI 为 `节.键`，如 `A.B.C` 对应 `[A.B]` 节的 `C` 键。

```
$读配置 <文件> <节点> <默认值>$          // 文件不存在或键为空时返回默认值（可省略，默认为空串）
$写配置 <文件> <节点> <值>$             // 文件不存在则自动新建，值可省略（默认为空串）
```

示例：

```
$读配置 a.ini Server.启用 false$          // 读取 [Server] 启用，无值时返回 "false"
$写配置 b.ini data.key yes$               // 写入 NebulaData/b.ini，不存在则新建
$读配置 config QQ.启用 false$             // 读取合并配置的 QQ.启用
$写配置 config.yaml Test.name hello$      // 写入合并配置的 Test.name
```

## 云工具状态

```
$云工具状态$
```

## 设置Ngrok

> 配置全局 Ngrok 隧道并立即启停生效。开关默认 `true`；密钥/域名默认空（空域名使用随机域名）；服务器地址默认空（转发核心服务器）。

```
$设置Ngrok 开关 密钥 域名 [服务器地址]$
$设置Ngrok$                                   // 全部省略：开启，随机域名，转发核心服务器
$设置Ngrok false$                             // 关闭 Ngrok 隧道
$设置Ngrok true 你的token example.ngrok.app$   // 开启并绑定固定域名
```
