# 词库执行器

在词库中执行另一段词库内容或词库文件。执行模式决定子词库与调用方之间「变量 / 自定义函数」的继承关系：

| 模式 | 变量 | 自定义函数 |
| ---- | ---- | ---- |
| `独立`（默认） | 全新变量 | 不继承 |
| `继承` | 复制调用方当前的变量 | 继承 |
| `继承函数` | 不继承 | 继承 |
| `互通` | 与调用方共用同一份变量（一方修改另一方可见） | 继承 |

## 执行词库

直接执行一段词库数据或一个词库文件（路径限制在私有目录内）。

```
$执行词库 <词库数据> <触发词|默认Main> <执行模式|默认独立>$
$执行词库文件 <文件路径> <触发词|默认Main> <执行模式|默认独立>$
```

```
$执行词库 "Main\n你好" Main$
$执行词库文件 dic/工具.n Sub 继承$
```

## 创建执行

`$创建执行$` 返回「词库执行器对象」（面对像），可在运行时设置执行模式、注入变量、设定函数黑白名单后反复执行。执行时按黑白名单拦截子词库调用的函数（默认黑名单为内置高危名单），并限制文件读写范围、禁止出网访问内网地址，名单规则同「创建执行沙箱」。

| 方法 | 说明 |
| ---- | ---- |
| `$执行器.设置执行模式 <模式>$` | 切换执行模式 |
| `$执行器.禁用函数 <函数名...>` | 追加到黑名单 |
| `$执行器.删除禁用函数 <函数名...>` | 从黑名单移除 |
| `$执行器.允许函数 <函数名...>` | 设置白名单（设置后进入白名单模式） |
| `$执行器.删除允许函数 <函数名...>` | 从白名单移除 |
| `$执行器.设置变量 <变量名> <值>$` | 注入变量 |
| `$执行器.执行 <词库数据> <触发词>` | 执行一段词库数据；触发词可省略，默认 `Main` |
| `$执行器.执行文件 <文件路径> <触发词>` | 执行词库文件；触发词可省略，默认 `Main` |

```
执行器:$创建执行 独立$
$执行器.设置执行模式 继承$
$执行器.禁用函数 创建终端 重启$
$执行器.设置变量 名字 张三$
$执行器.执行 "Main\n你好，%名字%" Main$
```

## 创建执行沙箱

`$创建执行沙箱$` 返回「执行沙箱对象」（面对像），用于在受限环境下执行不可信词库：默认屏蔽一批高危函数、限制文件读写范围、禁止出网访问内网地址。

| 方法 | 说明 |
| ---- | ---- |
| `$沙箱.禁用函数 <函数名...>` | 追加到黑名单 |
| `$沙箱.删除禁用函数 <函数名...>` | 从黑名单移除 |
| `$沙箱.允许函数 <函数名...>` | 设置白名单（设置后进入白名单模式） |
| `$沙箱.删除允许函数 <函数名...>` | 从白名单移除 |
| `$沙箱.设置变量 <变量名> <值>$` | 注入变量 |
| `$沙箱.执行 <词库数据> <触发词>` | 执行词库数据；触发词可省略，默认 `Main` |
| `$沙箱.执行文件 <文件路径> <触发词>` | 执行词库文件；触发词可省略，默认 `Main` |

```
s:$创建执行沙箱$
$s.禁用函数 创建终端 重启$
$s.设置变量 名字 张三$
$s.执行 "Main\n你好，%名字%"$
```

### 名单规则

1. 黑名单初始为内置高危名单（如 `创建终端`、`重启`、`创建WS`、`创建服务器`、`设置工作目录`、`PHP`、`Python` 等），可用 `禁用函数` / `删除禁用函数` 增删。
2. `允许函数` 一旦设置即切换为白名单模式：只放行名单内的函数，其余一律禁用。
3. 未设置白名单（或白名单为空）时按黑名单执行；黑名单也为空则回退到内置高危名单。即生效优先级为 **白名单 → 黑名单 → 内置高危名单**。
4. 名单以面对象变量为准：`%沙箱.禁用函数%`、`%沙箱.允许函数%` 是 JSON 数组文本（如 `["创建终端","重启"]`），可直接读取；也可直接给这两个变量赋值来改名单，改完下次执行即生效，无需调用方法。
5. 沙箱执行始终是独立模式，不继承调用方变量与自定义函数；需要向子词库传值请用 `设置变量`。
6. 沙箱内文件读写限定在调用方所属账号（用户根目录）内；出网禁止访问内网地址（公网不受影响）。
