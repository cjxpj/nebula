# 文件操作

## 读取数据

| 函数 | 说明 |
| ---- | ---- |
| `$读文件 database/a.txt 默认值$` | 读取文件全部文本（相对用户根目录） |
| `$读 路径 键 默认值$` | 在一个文件储存多个数据；只会写入到「储存」文件夹下 |
| `$读 文件路径$` | 可获取 json 列表 |
| `$读 a.json a.a$` | 后缀为 `.json` 时，键可用 `.` 读取多层 JSON 值 |
| `$读文件_随机一行 <路径> <默认值>$` | 随机一行；文件不存在返回默认值 |
| `$读文件_行数 <路径> <默认值>$` | 行数 |
| `$读文件行 <路径> <行数> <行数往下数量> <默认值>$` | 从指定行起连续取若干行 |
| `$读文件MD5 <路径>$` | 文件 MD5 |

## 写入数据

| 函数 | 说明 |
| ---- | ---- |
| `$写文件 database/a.txt 数据$` | 完全写入文本数据（相对用户根目录） |
| `$写 路径 键 数据$` | 在一个文件储存多个数据；只会写入到「储存」文件夹下 |
| `$写 a.json a.a ok$` | 后缀为 `.json` 时，键可用 `.` 写入多层 JSON 值 |

## 路径基准（两类函数不同，别混用）

- `$读/写 路径 键 数据$` 这类**键值**函数，路径从当前账号的 `储存/` 目录下开始解析；
- `$读文件` / `$写文件` 及其它文件操作类函数（存在 / 删除 / 列表 / 大小 / 重命名 / 复制 / 压缩解压 / MD5 / 属性 / 图片 / 下载等），路径从**用户根目录（账号目录）**下开始解析。

## 选型建议

简单键值数据（个人背包、任务进度、开关状态等）优先用 `$读 路径 键 默认值$` / `$写 路径 键 数据$` 存到 `储存/` 目录文件，简单直观、无需连接。只有需要余额增减、排行榜、多账号统计等**关系型数据**时，才使用「内置函数 → 全局数据库」的 `db_*` 系列。

## 储存习惯与路径组织

`$读/写 路径 键 数据$` 的路径都从 `储存/` 目录下开始：

- **路径分层用 `/` 分隔**，按「游戏/功能 → 分类 → 用户」组织，如 `$写 钓鱼/普通/123456.txt 背包 %背包%$`。
- **推荐「不用群号、专注 QQ」记录用户数据**：路径写 `<游戏名>/<分类>/<QQ>.txt`，同一用户在不同群、不同功能下用的是同一份数据；只有数据确实需要按群隔离时才用 `<群号>` 层。
- **文件名不要太长**：用 `<QQ>.txt`、`背包.json` 这类简短名字，需要描述信息就放进键名或文件内容里。
- **多拆分文件夹分类，一个文件夹下尽量全是文件、不要再有文件夹**，避免目录过深（如 `data/a/b/c/d.txt`）。
- 文件后缀用 `.txt`（文本数据）或 `.json`（结构数据，键支持 `.` 多层读写）。

## 查询

| 函数 | 说明 |
| ---- | ---- |
| `$文件大小 database/file.txt$` | 文件大小 |
| `$文件夹大小 database$` | 文件夹大小 |
| `$存在文件 database/a.txt$` | 返回 true / false |
| `$存在文件夹 database$` | 返回 true / false |
| `$存在文件或文件夹 database$` | 返回 true / false |
| `$文件列表 database$`、`$文件夹列表 database$` | 列表；参数留空为账号根目录 |
| `$文件后缀 a/a.txt$` | 从文件路径中取出最后的文件后缀 |

示例：`$文件夹列表$` 列出账号根目录下的子目录（如 `["机器人词库","储存","网站词库","私有","database"]`）。

> 没有「文件 + 文件夹」合并列表的函数，需要两者时分别调用 `$文件列表$` 与 `$文件夹列表$`。

## 管理

| 函数 | 说明 |
| ---- | ---- |
| `$删除文件 database/a.txt$` | 删除文件 |
| `$删除文件夹 database/缓存$` | 删除文件夹 |
| `$重命名 database database2$` | 重命名 / 移动，成功返回 true |
| `$复制粘贴 database database2$` | 复制粘贴，成功返回 true |
| `$ZIP压缩 database/文件夹 database/a.zip$` / `$ZIP解压 database/a.zip database/文件夹$` | ZIP 压缩 / 解压 |

## 下载文件

```
// 异步下载，返回任务对象
$下载文件 <url> <文件路径>$
// 线程传 0 表示按文件大小自适应（2~8）
$下载文件 <url> <文件路径> <线程|0>$
// 第 4 个参数控制是否在终端打印下载进度
$下载文件 <url> <文件路径> <线程|0> <下载进度打印终端|false>$
```

`<文件路径>` 与其它文件操作类函数一致，从**用户根目录（账号目录）**下开始解析，必须是相对路径（不支持绝对路径，也不能用 `..` 越界）。

返回任务对象（下载在后台进行，函数立即返回），可用对象方法实时查询：`进度`（0-100）、`速度`（MB/s）、`已下载`（字节）、`总大小`（字节）、`状态`（下载中 / 完成 / 失败）、`错误`。

```
任务:$下载文件 https://example.com/a.zip database/a.zip 0$
$任务.进度$
$任务.速度$
$任务.状态$
```

### 完整示例：下载并等待完成

下载在后台进行，要等文件真正下载完再处理，就得轮询 `状态` 直到「完成」或「失败」：

```n
下载测试
// 下载到 database/a.zip：第 3 参 0 = 线程按文件大小自适应（2~8），第 4 参 true = 在终端打印进度
任务:$下载文件 https://example.com/a.zip database/a.zip 0 true$
// 每 500 毫秒查一次状态，最多 60 次（约 30 秒）
循环>i=60
    状态:$任务.状态$
    如果>%状态%==完成
        进度:$任务.进度$
        速度:$任务.速度$
        已下载:$任务.已下载$
        总大小:$任务.总大小$
        下载完成，进度 %进度%，速度 %速度% MB/s，已下载 %已下载% / %总大小% 字节
        >终止循环
    <如果
    如果>%状态%==失败
        错误:$任务.错误$
        下载失败：%错误%
        >终止循环
    <如果
    $延迟 500$
<循环
```

要点：

- `任务` 是 `$下载文件$` 返回的任务对象，用 `$任务.状态$` 一类方法查询；
- 状态为「下载中」时既不是「完成」也不是「失败」，只延时后继续下一轮；
- 轮询要有上限（这里 60 次），避免下载卡住时死等；超过上限退出循环时，下载仍在后台继续。

## 文件属性

获取文件属性，返回 JSON 对象（键为属性名，值为 true/false）。仅 Windows 生效，非 Windows 返回空对象。

```
$文件属性 <文件路径>$
$文件属性 database/a.txt$
```

返回 `{"只读":false,"隐藏":false,"系统":false,"存档":true,"目录":false,"临时":false,"压缩":false,"离线":false,"非内容索引":false,"加密":false}`

## 设置文件属性

设置文件属性，第二参数为逗号分隔的属性名列表（只读、隐藏、系统、存档、临时、非内容索引），置位指定属性；传「正常」清除全部属性。仅 Windows 生效，返回 true/false。

```
$设置文件属性 <文件路径> <属性名列表|正常>$
$设置文件属性 database/a.txt 只读,隐藏$
$设置文件属性 database/a.txt 正常$
```

## 设置工作目录

切换进程当前工作目录，后续相对路径（文件读写、配置、资源等）基于该目录解析。参数可为相对或绝对路径。

```
$设置工作目录 NebulaData$
```

> 桌面端默认不再内置固定数据目录，请在启动词库 `start.n` 的 `[f]_初始化`（或头部）中调用本函数确定数据目录；后续 `config.yaml`、`router.n` 等配置在确定目录后再加载。

## 设置系统变量

设置引擎的系统级变量（键规范化为 `_名_`，供 Go 侧读取），参数为 `<名> <值>`，名称两侧的下划线可省略。

```
$设置系统变量 日志目录 database/log$
$设置系统变量 终端词库路径 private/system/terminal.n$
```

> 只在启动词库 `start.n` 的 `[f]_初始化`（或头部）调用，用来配置 `日志目录`、`终端词库路径` 等启动项；该函数在沙箱中默认被禁用，普通用户词库不要依赖它。
