# 文件操作

## 读取数据

```
$读文件 database/a.txt 默认值$   // 读取文件全部文本
$读 路径 键 默认值$              // 在一个文件储存多个数据，只会写入到 database 文件夹下
$读 文件路径$                    // 可获取 json 列表
$读 a.json a.a$                  // 后缀为 .json 时，键可用 . 读取多层 JSON 值
$读文件_随机一行 <路径> <默认值>$   // 文件不存在返回默认值
$读文件_行数 <路径> <默认值>$
$读文件行 <路径> <行数> <行数往下数量> <默认值>$
$读文件MD5 <路径>$
```

## 写入数据

```
$写文件 database/a.txt 数据$   // 完全写入文本数据
$写 路径 键 数据$              // 在一个文件储存多个数据，只会写入到 database 文件夹下
$写 a.json a.a ok$             // 后缀为 .json 时，键可用 . 写入多层 JSON 值
```

> **选型建议**：简单键值数据（个人背包、任务进度、开关状态等）优先用 `$读 路径 键 默认值$` / `$写 路径 键 数据$` 存到 `database/` 目录文件，简单直观、无需连接。只有需要余额增减、排行榜、多账号统计等**关系型数据**时，才使用「内置函数 → 全局数据库」的 `db_*` 系列。

### 储存习惯与路径组织

`$读/写 路径 键 数据$` 的路径都从 `database/` 目录下开始：
- **路径分层用 `/` 分隔**，按「游戏/功能 → 分类 → 用户」组织，如 `$写 钓鱼/普通/123456.txt 背包 %背包%$`。
- **推荐「不用群号、专注 QQ」记录用户数据**：路径写 `<游戏名>/<分类>/<QQ>.txt`，同一用户在不同群、不同功能下用的是同一份数据；只有数据确实需要按群隔离时才用 `<群号>` 层。
- **文件名不要太长**：用 `<QQ>.txt`、`背包.json` 这类简短名字，需要描述信息就放进键名或文件内容里。
- **多拆分文件夹分类，一个文件夹下尽量全是文件、不要再有文件夹**，避免目录过深（如 `data/a/b/c/d.txt`）。
- 文件后缀用 `.txt`（文本数据）或 `.json`（结构数据，键支持 `.` 多层读写）。

## 下载文件

```
// 异步下载，返回任务对象
$下载文件 <url> <文件路径>$
// 线程传 0 表示按文件大小自适应（2~8）
$下载文件 <url> <文件路径> <线程|0> <下载进度打印终端|false>$
```

> 返回任务对象，可用对象方法实时查询：`进度`（0-100）、`速度`（MB/s）、`已下载`、`总大小`、`状态`（下载中/完成/失败）、`错误`

```
任务:$下载文件 https://example.com/a.zip /save/a.zip 0$
$任务.进度$
$任务.速度$
$任务.状态$
```

## 文件列表

文件夹留空为站点目录

```
$文件列表 database$ / $文件夹列表 database$ / $文件跟文件夹列表 database$
```

示例 `$文件夹列表$` 返回 `["database","private","public"]`

## 设置工作目录

切换进程当前工作目录，后续相对路径（文件读写、配置、资源等）基于该目录解析。参数可为相对或绝对路径。

```
$设置工作目录 NebulaData$
```

> 桌面端默认不再内置固定数据目录，请在启动词库 `start.n` 头部调用本函数确定数据目录；后续 `config.yaml`、`router.n` 等配置在确定目录后再加载。

## 文件属性

获取文件属性，返回 JSON 对象（键为属性名，值为 true/false）。仅 Windows 生效，非 Windows 返回空对象。

```
$文件属性 <文件路径>$
$文件属性 database/a.txt$
```

返回 `{"只读":false,"隐藏":false,"系统":false,"存档":true,"目录":false,"临时":false,"压缩":false,"离线":false,"非内容索引":false,"加密":false}`

## 设置文件属性

设置文件属性，第二参数为逗号分隔的属性名列表（只读、隐藏、系统、存档、临时、非内容索引），置位指定属性；传「正常」清除全部属性。仅 Windows 生效，返回 true/false。

```
$设置文件属性 <文件路径> <属性名列表|正常>$
$设置文件属性 database/a.txt 只读,隐藏$
$设置文件属性 database/a.txt 正常$
```
