# HTML 组件

## 创建HTML

> 创建一个 HTML 组件对象（面向对象），可选参数为页面标题。返回的对象用「设置*」方法逐块拼接页面，「创建布局」新开一个容器并返回该容器的分支句柄，「获取」输出拼装好的 HTML 字符串。

```
H:$创建HTML$
H:$创建HTML 我的站点$
```

对象方法与全局函数一样写在 `$...$` 里，写法是 `$对象.方法 参数$`。除「创建布局」会返回布局句柄（要用赋予值接住，见下节）外，其余方法都作用于对象自身，不需要接收返回值。

参数以空格分隔，参数本身含空格时（一段带空格的文字、一条含多个选择器的 CSS、一段带属性的 HTML）必须用双引号包住整段，参数里的双引号写成 `\"`：

```
$H.设置文本 "© 2026 我的站点"$
$H.设置样式 "body{background:#f7f8fa} .高亮{color:#ef4444}"$
$H.设置原始 "<div class=\"自定义\">自定义结构</div>"$
```

## 创建布局

> 在对象当前所在的位置新建一个布局容器并进入该容器，之后的「设置*」都追加到容器内部；同时返回该容器的**布局句柄**（分支函数），用赋予值接住后就能随时回到这个分支继续操作。布局按层级自动嵌套：开新布局时自动闭合「同层或更深」的布局，所以**不需要手动结束**，写下一个布局就等于退回到上一层。

```
H:$创建HTML 我的站点$
$H.创建布局 页面$
$H.创建布局 容器$
卡片:$H.创建布局 卡片$
$卡片.设置文本 卡片里的内容$
```

例子里 `页面`（层级 0）→ `容器`（层级 1）→ `卡片`（层级 4）层层进入；再写 `$H.创建布局 页脚$`（层级 2）时，`卡片` 因为更深而自动闭合，`页脚` 挂到 `容器` 下；若接着写 `$H.创建布局 内容$`，两者同层，`页脚` 也自动闭合，`内容` 与 `页脚` 成为兄弟节点。

返回值是新容器的句柄，**要用赋予值接住**（写成 `句柄:$H.创建布局 名称$`）才能拿到；不接住也不影响布局本身，只是拿不到这个分支的控制权。有了句柄就能在它下面继续开子布局、继续放内容，层级规则与整页写法完全一致：

```
H:$创建HTML 我的站点$
页面:$H.创建布局 页面$
容器:$H.创建布局 容器$
页头:$H.创建布局 页头$
$页头.创建布局 横向$
$页头.设置文本 站点名 品牌$
内容:$H.创建布局 内容$
$内容.设置文本 欢迎回来$
$内容.设置按钮 查看文档 /docs 主要$
$容器.创建布局 页脚$
```

`$页头.创建布局 横向$` 是在「页头」分支里再开一层（层级 3 比页头深，所以嵌进去）；随后 `$页头.设置文本 站点名 品牌$` 又把位置切回「页头」，内容追加在「横向」之后。`$H.创建布局 内容$` 里「内容」与「页头」同层，所以「页头」自动闭合，「内容」成为「容器」下的兄弟节点。

第二个参数可省略：写 `#名称` 会作为 `id`，其它内容作为附加 `class`（可以写内置样式名，见「内置样式名」一节）。

```
$H.创建布局 内容 #main$
$H.创建布局 卡片 高亮$
$H.创建布局 卡片 悬停$
```

布局名称与生成的标签、类名、层级：

| 名称 | 标签 | 类名 | 层级 |
| ---- | ---- | ---- | ---- |
| 页面 | div | nebula-page | 0 |
| 全屏 / 全屏颜色 | div | nebula-fullscreen | 0 |
| 全屏居中 / 屏幕居中 / 居中布局 | div | nebula-center | 0 |
| 居中卡片 | div | nebula-center-card | 0 |
| 容器 / 居中 | div | nebula-container | 1 |
| 顶部 / 页头 | header | nebula-header | 2 |
| 底部 / 页脚 | footer | nebula-footer | 2 |
| 主体 / 内容 | main | nebula-main | 2 |
| 导航 / 导航栏 | nav | nebula-nav | 2 |
| 侧栏 / 侧边栏 | aside | nebula-aside | 2 |
| 分区 / 区域 | section | nebula-section | 2 |
| 卡片 | div | nebula-card | 4 |
| 横向 / 行 | div | nebula-row | 3 |
| 纵向 / 列 | div | nebula-col | 3 |
| 网格 | div | nebula-grid | 3 |
| 表单 | form | nebula-form | 3 |

层级决定自动闭合的时机：0 是整屏骨架，1 是容器，2 是区块，3 是排列容器（行 / 列 / 网格 / 表单），4 是组件（卡片）。所以「网格 / 行」里能放「卡片」，「卡片」之间同层会自动收尾成并排。表里没有的名称会退化为 `<div class="名称">`，按最深的层级 4 处理，例如 `$H.创建布局 我的盒子$` → `<div class="我的盒子">`。在布局句柄上开新布局时，同样按这套层级相对该分支自动闭合。

常用骨架：

- `页面`：整屏纵向骨架，配 `页头` / `内容` / `页脚` 撑满高度；
- `全屏`：整屏容器，内容自上而下排列，自带四周留白；
- `全屏居中`：整屏居中，内容水平垂直都在中间，适合登录页、落地页；
- `居中卡片`：整屏居中，并把内部第一层子节点自动变成一张卡片（圆角、阴影、最大宽度 420px），适合「居中一块表单」。

## 设置页面标题 / 设置语言 / 设置样式 / 设置元信息 / 设置图标 / 设置脚本

> 页面头部与尾部信息。`设置样式` 追加一段 CSS，`设置脚本` 追加一段脚本到 `</body>` 前，两者都可以多次调用。

```
$H.设置页面标题 我的站点$
$H.设置语言 zh-CN$
$H.设置元信息 description 一个演示页面$
$H.设置图标 /favicon.ico$
$H.设置样式 "body{background:#f7f8fa} .高亮{color:#ef4444}"$
$H.设置脚本 console.log("ok")$
```

内置的整套预设 CSS **每次渲染都会自动插入** `<head>`，不需要手动启用。这套预设包含：

- **主题变量**：颜色、圆角、阴影、焦点环统一收在 `--nebula-*` 变量里（`--nebula-primary` / `--nebula-bg` / `--nebula-surface` / `--nebula-text` / `--nebula-muted` / `--nebula-border` / `--nebula-radius` / `--nebula-shadow` / `--nebula-ring` / `--nebula-hero-from` / `--nebula-hero-to` / `--nebula-badge-bg` / `--nebula-badge-text`），改主题只改这几个变量；
- **全局背景**：`<body>` 默认就有全局背景色与文字颜色（`background:var(--nebula-bg)` / `color:var(--nebula-text)`），并撑满一屏，无需额外设置；
- **深色 / 浅色**：`<body>` 上挂 `.nebula-theme-dark` 或 `.nebula-theme-light` 即整套换肤（用 `设置背景` 挂载，见下）；
- **排版**：标题 h1~h6 的层级字号、段距、链接、列表、分割线、图片圆角；
- **组件**：`.nebula-card` 卡片、`.nebula-btn` 系列按钮、`.nebula-form` 表单、`.nebula-grid` 自适应网格、`.nebula-row` / `.nebula-col` 横向纵向排列；
- **模板类**：`.nebula-hero` 主视觉、`.nebula-badge` 徽标、`.nebula-lead` 引导文案、`.nebula-icon` 图标、`.nebula-muted` 弱化文字、`.nebula-hover` 悬停浮起、`.nebula-actions` 按钮组、`.nebula-brand` 品牌名（见「内置样式名」）；
- **响应式**：`max-width:640px` 时容器收窄、侧栏变整行、横排自动转纵排。

想局部覆盖，用 `设置样式` 写自己的 CSS，就能盖住预设的同名规则（默认样式总在最前，用户样式排在其后）。

## 内置样式名

> 常用版式已经内置成固定模板，写中文样式名就能套上，**不用自己写 CSS**。写法是在各「设置*」方法最后那个「附加类名」参数上直接写样式名。

| 样式名 | 别名 | 内置类名 | 效果 |
| ---- | ---- | ---- | ---- |
| 品牌 | brand | nebula-brand | 站点名：加粗、字号略大、字距收紧 |
| 主视觉 | hero / 首屏 | nebula-hero | 渐变主视觉大卡片，内部标题 / 徽标 / 引导 / 按钮自动转成白色系 |
| 徽标 | badge / tag / 标签 | nebula-badge | 小圆角胶囊标签 |
| 引导 | lead / 引言 | nebula-lead | 副标题式引导文案，字号略大、限宽 |
| 图标 | icon | nebula-icon | 表情 / 图标，字号加大并留出下边距 |
| 弱化 | muted / 次要文字 | nebula-muted | 次要说明文字，颜色变淡 |
| 悬停 | hover / 悬浮 | nebula-hover | 鼠标移入时上浮并加深阴影 |
| 按钮组 | actions / 操作 | nebula-actions | 一排按钮横向排列并自动换行 |

```
H:$创建HTML 我的站点$
$H.设置背景 深色$
$H.创建布局 容器$
$H.创建布局 页头$
$H.创建布局 横向$
$H.设置文本 Nebula 品牌$
$H.设置链接 首页 /$
$H.创建布局 内容$
$H.创建布局 卡片 主视觉$
$H.设置文本 组件化建站 徽标$
$H.设置标题 测试标题$
$H.设置文本 测试内容 引导$
$H.设置按钮 查看文档 /docs 主要$
$H.创建布局 网格$
$H.创建布局 卡片 悬停$
$H.设置文本 🧩 图标$
$H.设置标题 测试标题 3$
$H.设置文本 测试内容 弱化$
网页:$H.获取$
```

「附加类名」参数写内置样式名以外的东西时，会原样当作 `class`，所以仍可写自己的类名配 `设置样式` 用。多个值不能空格隔开（参数本身以空格切分），需要叠加时用自己的类名再在 `设置样式` 里组合。

## 设置背景

> 设置整页背景，始终作用于 `<body>`（与当前是否在布局中无关）。写 `深色` / `dark` 切换为预设深色主题，`浅色` / `light` 切回浅色主题，其它值当作 CSS `background` 直接用（颜色、渐变、`url(...)` 都可以）。

```
$H.设置背景 深色$
$H.设置背景 浅色$
$H.设置背景 #0b1220$
$H.设置背景 linear-gradient(135deg,#4f46e5,#0ea5e9)$
```

深色主题下再配 `全屏居中` 或 `居中卡片`，就是一个完整的登录页骨架：

```
H:$创建HTML 登录$
$H.设置背景 深色$
$H.创建布局 居中卡片$
$H.设置标题 欢迎回来 2$
$H.设置输入框 用户名 请输入用户名$
$H.设置输入框 密码 请输入密码 password$
$H.设置按钮 登录 - 主要$
网页:$H.获取$
```

## 设置属性

> 给当前打开的布局容器设置属性；没有打开的布局时，属性写在 `<body>` 上。

```
$H.设置属性 data-theme dark$
$H.创建布局 内容$
$H.设置属性 id main$
```

## 设置标题 / 设置文本 / 设置列表 / 设置分割线

> 常用文本类组件。`设置标题` 的参数依次为 文本、级别、附加类名，级别 1~6 可省略（默认 1）；`设置文本` 生成 `<p>`，第二个参数为附加类名。附加类名写内置样式名即可套用固定模板（见「内置样式名」）。

```
$H.设置标题 一级标题$
$H.设置标题 二级标题 2$
$H.设置标题 测试标题 2 主视觉$
$H.设置文本 一段正文$
$H.设置文本 提示文字 弱化$
$H.设置文本 🧩 图标$
$H.设置列表 甲 乙 丙$
$H.设置分割线$
```

## 设置按钮

> 按钮文本、链接、样式、附加类名依次可省略。附加类名可写内置样式名，例如 `悬停`。
>
> - 链接写地址时输出 `<a href="地址">`；写 `-` 或省略时输出 `<button type="button">`（纯按钮，配合页面上的普通 JS 使用）；
> - 样式可用：主要 / 次要 / 成功 / 警告 / 危险 / 幽灵（也支持 primary / secondary / success / warning / danger / ghost），其它值直接当作附加类名。

```
$H.设置按钮 提交$
$H.设置按钮 提交 - 主要$
$H.设置按钮 去首页 /about 次要$
$H.设置按钮 危险操作 - 危险 靠右$
```

## 设置链接 / 设置图片 / 设置输入框

> 链接与图片的文本 / 地址都不能为空；`设置输入框` 的类型可省略（默认 text），参数依次为 名称、占位文字、类型、类名。三者最后的类名参数都可以写内置样式名。

```
$H.设置链接 官网 https://example.com$
$H.设置链接 官网 https://example.com 外部链接$
$H.设置图片 /logo.png 站点标志$
$H.设置图片 /logo.png 站点标志 圆角$
$H.设置输入框 用户名$
$H.设置输入框 用户名 请输入用户名$
$H.设置输入框 密码 请输入密码 password$
$H.设置输入框 邮箱 请输入邮箱 email 表单控件$
```

## 设置原始

> 插入一段原始 HTML，不做转义。其它「设置*」方法里的文本都会被转义（写 `<b>加粗</b>` 只会显示字面文本），需要贴自定义标签、内嵌 `<style>` / `<script>` 片段时用这个方法。

```
$H.设置原始 "<div class=\"自定义\">自定义结构</div>"$
```

## 获取

> 输出拼装好的 HTML 字符串。参数可省略：不写（或写「完整」）输出整份文档、写「片段」/「主体」只输出 `<body>` 里的内容、写「头部」只输出 `<head>` 里的内容。

```
H:$创建HTML 我的站点$
$H.创建布局 容器$
$H.设置标题 你好$
$H.设置按钮 提交 - 主要$
// 整份文档：<!DOCTYPE html> ... </html>
全页:$H.获取$
// 只有 <body> 里的内容
片段:$H.获取 片段$
// 只有 <head> 里的内容
头部:$H.获取 头部$
%片段%
```

```
$H.设置背景 深色$
// 页头导航
$H.创建布局 容器$
$H.创建布局 页头$
$H.创建布局 横向$
$H.设置文本 Nebula 品牌$
$H.设置链接 首页 /$
$H.设置链接 文档 /docs$
// 主视觉区
$H.创建布局 内容$
$H.创建布局 卡片 主视觉$
$H.设置文本 组件化建站 徽标$
$H.设置标题 测试标题$
$H.设置文本 测试内容 引导$
$H.设置按钮 查看文档 /docs 主要$
$H.设置按钮 在线示例 /demo 幽灵$
// 功能卡片
$H.创建布局 网格$
$H.创建布局 卡片 悬停$
$H.设置文本 🧩 图标$
$H.设置标题 测试标题 3$
$H.设置文本 测试内容 弱化$
$H.创建布局 卡片 悬停$
$H.设置文本 🎨 图标$
$H.设置标题 测试标题 3$
$H.设置文本 测试内容 弱化$

$H.设置文本 测试内容$
网页:$H.获取$
%网页%
?>
```

生成的 HTML（节选，`<style>` 里是自动插入的预设样式）：

```
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>Nebula 词库</title>
  <style>...</style>
</head>
<body class="nebula-theme-dark">
<div class="nebula-container">
  <header class="nebula-header">
    <div class="nebula-row">
      <p class="nebula-brand">Nebula</p>
      <a href="/">首页</a>
      <a href="/docs">文档</a>
    </div>
  </header>
  <main class="nebula-main">
    <div class="nebula-card nebula-hero">
      <p class="nebula-badge">组件化建站</p>
      <h1>测试标题</h1>
      <p class="nebula-lead">测试内容</p>
      <a class="nebula-btn nebula-btn-primary" href="/docs">查看文档</a>
      <a class="nebula-btn nebula-btn-ghost" href="/demo">在线示例</a>
    </div>
    <div class="nebula-grid">
      <div class="nebula-card nebula-hover">
        <p class="nebula-icon">🧩</p>
        <h3>测试标题</h3>
        <p class="nebula-muted">测试内容</p>
      </div>
      <div class="nebula-card nebula-hover">
        <p class="nebula-icon">🎨</p>
        <h3>测试标题</h3>
        <p class="nebula-muted">测试内容</p>
      </div>
    </div>
  </main>
  <footer class="nebula-footer">
    <p>测试内容</p>
  </footer>
</div>
</body>
</html>
```

> `获取` 返回的是普通文本，不是模板数据：在网页词库里把结果赋值后用 `%变量%` 就地输出，就绕开了 `{{.键}}` 一律 HTML 转义的限制。所以可以写一个「薄壳」`.wn`：整个文件只有一个内联块，块里拼好页面再用 `%网页%` 输出（`.wn` 管线会对结果再做一次 HTML 规范化，如 `<hr>` 输出成 `<hr/>`）；也可以只取「片段」，插进已有页面的某个位置。`.n` 词库里同样可用：`%网页%` 直接输出，或配合 `$写文件 页面.html %网页%$` 落盘。
