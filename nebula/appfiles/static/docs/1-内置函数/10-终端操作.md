# 终端操作

`$创建终端$` 与 `$创建Shell终端$` 返回「终端对象」（面对像），通过 `$对象.方法$` 操作该终端。

```
// 直接执行可执行文件，参数按空格分隔逐个传入
cmd:$创建终端 ./NebulaData/forFmt.exe 参数1 参数2$
// 通过系统 Shell 执行（支持管道、重定向、内置命令；Linux 用 bash -c，Windows 用 cmd /c）
cmd:$创建Shell终端 ls -la | grep foo$
```

**终端对象方法**

```
$cmd.解码器 <编码>$       // 设置输出解码器（终端输出乱码时使用）
$cmd.变量 <键=值>$        // 设置临时环境变量
$cmd.执行目录 <路径>$     // 设置工作目录
$cmd.输入 <内容>$         // 向终端标准输入写入内容（不自动补换行）
$cmd.执行$                // 同步执行并等待结束，返回全部输出（stdout+stderr）
$cmd.异步执行$            // 后台异步执行，立即返回（不返回输出）
$cmd.断开$                // 终止进程，返回 "true" / "false"
```

**监听执行 / 常用输出编码**

```
// 逐行监听终端输出，每一行作为触发词执行指定词库
$终端_监听执行 %cmd% private/cmd.n$

// 常用输出编码
中文：UTF-8、GBK/GB18030、Big5；日文：Shift-JIS、EUC-JP、ISO-2022-JP
韩文：EUC-KR；西欧：ISO-8859-1、Windows-1252
```

> 前端「实时终端」输入会作为触发词运行专用词库 `private/system/terminal.n`（首次启动自动创建），输出回显到终端；可用 `%括号0%` 读取本次输入全文、`%参数N%` 读取按空格分割的匹配文本。

## MC终端颜色

将文本按 Minecraft 颜色码转换为终端 ANSI 颜色文字，配合「实时终端」显示彩色输出。

```
$MC终端颜色 <含§颜色码的文本>$
```

- 支持颜色码 `§0`~`§9`、`§a`~`§f`，格式码 `§k`（随机乱码）、`§l`（粗体）、`§o`（斜体）、`§n`（下划线）、`§m`（删除线），以及重置码 `§r`（恢复默认）；其它格式码（如 `§x` 自定义颜色等）原样保留。

示例（实时终端命令输入）：

```
$打印 $MC终端颜色 §e你好§c世界$$
```

MC 颜色字符对照（`0`~`9` 为深色系、`a`~`f` 为亮色系）：

| 字符 | MC 颜色 | 终端显示 | 字符 | MC 颜色 | 终端显示 |
| ---- | ------- | -------- | ---- | ------- | -------- |
| `0` | 黑色 | 黑 | `8` | 深灰色 | 亮黑 |
| `1` | 深蓝色 | 蓝 | `9` | 蓝色 | 亮蓝 |
| `2` | 深绿色 | 绿 | `a` | 绿色 | 亮绿 |
| `3` | 深青色 | 青 | `b` | 青色 | 亮青 |
| `4` | 深红色 | 红 | `c` | 红色 | 亮红 |
| `5` | 深紫色 | 紫 | `d` | 亮紫色 | 亮紫 |
| `6` | 金色 | 黄 | `e` | 黄色 | 亮黄 |
| `7` | 灰色 | 白 | `f` | 白色 | 亮白 |
