# 随机数 / 随机文本

```
%随机数1-100%
$随机数 1 100$
$随机文本 abc$        // 随机一个字符返回
$随机文本 , a,b,c$    // 随机一个文本组返回（首参为分隔符）
// 后面定义数量
$随机大小字母 3$
$随机小写字母 3$
$随机大写字母 3$
$随机大小字母数字 3$
$随机大写字母数字 3$
$随机小写字母数字 3$
$随机数字 3$
// 固定随机种子，使后续随机数序列可复现
$设置随机种子 42$
// 均匀分布小数（无参 [0,1)，两参 [min,max)）
$随机小数$
$随机小数 1 10$
// 正态分布（无参标准正态 N(0,1)，两参 N(均值,标准差)）
$正态分布$
$正态分布 100 15$
// 指数分布（λ 率参数，均值 = 1/λ，省略默认 1）
$指数分布 2$
```
