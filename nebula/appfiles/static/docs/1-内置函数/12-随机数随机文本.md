# 随机数 / 随机文本

| 调用 | 说明 |
| ---- | ---- |
| `%随机数1-100%` | 范围随机数（变量取值写法） |
| `$随机数 1 100$` | 指定范围随机数 |
| `$随机文本 abc$` | 随机一个字符返回 |
| `$随机文本 , a,b,c$` | 随机一个文本组返回（首参为分隔符） |
| `$随机大小字母 3$` | 随机大小写混合字母，参数为数量 |
| `$随机小写字母 3$` | 随机小写字母 |
| `$随机大写字母 3$` | 随机大写字母 |
| `$随机大小字母数字 3$` | 随机字母 + 数字（大小写混合） |
| `$随机大写字母数字 3$` | 随机大写字母 + 数字 |
| `$随机小写字母数字 3$` | 随机小写字母 + 数字 |
| `$随机数字 3$` | 随机数字 |
| `$设置随机种子 42$` | 固定随机种子，使后续随机数序列可复现 |
| `$随机小数$` / `$随机小数 1 10$` | 均匀分布小数：无参 `[0,1)`，两参 `[min,max)` |
| `$正态分布$` / `$正态分布 100 15$` | 正态分布：无参为标准正态 N(0,1)，两参为 N(均值,标准差) |
| `$指数分布 2$` | 指数分布（λ 为率参数，均值 = 1/λ，省略默认 1） |
