# 解析与转换

## HTML解析

> 解析 HTML，根据路径获取节点。容器节点（含子元素）返回 JSON 节点数组，叶子节点（纯文本）返回文本数组。末尾数字参数作为索引选取单个节点。

```
a:<html><head><title>标题</title></head><body><h1>文本</h1><h1>文本2</h1><p>文本2</p></body></html>
$HTML解析 %a%$                  // 不指定路径 → 返回完整 JSON 树
$HTML解析 %a% html head title$  // 叶子节点 → 文本数组 ["标题"]
$HTML解析 %a% html body h1$     // ["文本","文本2"]
$HTML解析 %a% html body$        // 容器节点 → JSON 节点数组 [{h1节点},{h1节点},{p节点}]
$HTML解析 %a% html body h1 0$   // 索引选取 → 叶子返回 "文本"
$HTML解析 %a% html body 0$      // 索引选取 → 容器返回 {h1节点JSON}
```

## 正则

> 正则写法以 Go 语言为准。Java 里常用的「环视/预查」`(?=...)`、`(?<=...)`、「反向引用」`\1`，以及 `\uXXXX`（Unicode 字符）在 Go 里都不支持，Unicode 字符要改用 `\x{XXXX}` 写；普通匹配照常写即可，比如 `\d+` 匹配数字、`^abc` 匹配开头、`[abc]` 匹配 a/b/c 之一。

```
// 正则匹配内容返回json
$正则 正则 内容$
$正则 \d+ abc123$       // 返回 ["123"]
$正则 (a)(\d+) a123$    // 返回 ["a123","a","123"]

// 正则匹配只会返回true/false
$正则匹配 正则 内容$
$正则匹配 \d+ 123$      // 返回 true
$正则匹配 \d+ abc$      // 返回 false
```
