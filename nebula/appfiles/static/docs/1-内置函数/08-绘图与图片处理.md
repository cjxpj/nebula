# 绘图与图片处理

## 绘图

字体在内部文件夹的字体文件夹内；一个绘图函数中仅支持一个创建。

| 需求 | 参数 | 所需 |
| ---- | ---- | ---- |
| 创建 | 1/2 | img:Base64\|x/y |
| 二维码 | 1 | string |
| 颜色 | 3/4 | R/G/B/A |
| 画字 | 1/3 | string/x/y |
| 字体 | 1 | file |
| 大小 | 1 | string:int |
| 伽马值 / 模糊 / 锐化 / 对比度 / 亮度 / 饱和度 | 1 | string:int |
| 画圆 | 2 | x/y |
| 画方 / 画线 | 4 | x始/y始/x终/y终 |
| 画虚线 | 6 | x始/y始/x终/y终/l长/s间隔 |
| 贴图 | 3/5/6 | img:Base64/x/y/w宽/h高/0.1~1透明度 |
| 插图 | 1/2 | times/img:Base64 |
| 输出 | 1 | gif/png/jpg/jpeg/信息 |

| 重构需求 | 参数 | 所需 |
| ---- | ---- | ---- |
| 圆形 | 0/1 | size |
| 圆角矩形 | 2/4 | x/y/dx/dy |
| 旋转 | 0/1 | rotate0~360 |

### 示例仅供参考

```json
$全局变量 输出类型 image/png$
文本>画=
[
    {"需求":"颜色","参数":["255","255","255","255"]},
    {"需求":"创建","参数":["380","520"]},
    {"需求":"颜色","参数":["0","0","0","255"]},
    {"需求":"大小","参数":["25"]},
    {"需求":"画字","参数":["酒乐文游","135","80"]},
    {"需求":"颜色","参数":["255","0","0","128"]},
    {"需求":"画方","参数":["200","200","250","250"]},
    {"需求":"输出","参数":["png"]}
]
<文本
$绘图 %画%$
```

## 画布

创建画布需要赋予值（返回面对像对象）。第三个参数为背景色（`#十六进制` 或颜色对象），不写时默认黑色（`#000000`，不透明）。

```
a:$创建画布 <高> <宽>$
a:$创建画布 <高> <宽> <#十六进制|颜色地址>$
a:$创建画布 <URL> <高> <宽>$
a:$创建画布 <文件路径> <高> <宽>$
a:$创建画布 <图片字符串数据> <高> <宽>$
// 生成图片 默认png格式
$a.获取$
$a.获取 png|jpg|jpeg$
```

仅 **.n 词库**可以直接展示画布，不需要保存成文件：把 `$a.获取 png$` 返回的图片原数据单独输出到正文，运行结果面板会自动识别并显示。

```
画布:$创建画布 100 100$
$画布.绘制方形 0 0 20 20 0 #ff0000$
图:$画布.获取 png$
%图%
```

> `$a.获取$` 的输出只在 **.n 词库**中会进入词库输出（运行结果面板会把它当作图片显示）；**网页词库 `.wn`** 的执行块（`<?n ... ?>` 内联块 / `<script type="nebula">` 脚本块）输出不会进入页面，图片二进制也不能整串通过 `{{.键}}` 插入 HTML（会被 Go 模板的 URL 过滤器换成 `#ZgotmplZ`）。但 `.wn` 用画布产图是支持的，两种把图片交给页面的写法：
> ① 模板里写 `data:` 字面前缀、变量只放 base64 正文：块里写 `b64:$B64编码 %图2%$`，HTML 写 `<img src="data:image/png;base64,{{.b64}}">`（前缀必须是模板里的字面量，整串 data URI 放进变量就会被拒）；
> ② 落盘成静态文件：块里写 `$写文件 public/out.png %图2%$`，HTML 写 `<img src="/out.png">`。
> 只有赋值后既不进模板、也不落盘才是无意义的死代码。页面上纯前端绘制的图形仍可直接用 HTML/CSS 或浏览器原生 `canvas`（canvas 的 JS 必须写在普通 `<script>` 里）。

画布没有保存 / 导出 / 转 / 输出图片的方法，禁止写 `$画布.保存图片 1.png$`、`$画布.导出图片 1.png$`、`$画布.转图片$`、`$画布.输出图片$`、`$画布.写文件 1.png$`（这些方法都不存在）。也不要用 `$写图片 <文件路径> %图%$` 当「导出」：`$写图片$` 是把数据隐写进一张**已存在**的图片，目标文件不存在会报「无法打开或解码图片文件」，与展示画布无关。要把 `$a.获取$` 的结果存成图片文件，用通用的 `$写文件 <文件路径> %图%$`（按原始字节写入）。

绘制

```
$a.绘制图片 <图片> <高> <宽> <旋转> <x> <y> <透明度> <半径>$    // 旧名：$a.图片$
$a.绘制方形描边 <X> <Y> <宽> <高> <圆润> <颜色>$                 // 旧名：$a.方形描边$
$a.绘制方形 <X> <Y> <宽> <高> <圆润> <颜色>$                     // 旧名：$a.方形$
$a.绘制椭圆描边 <X1> <Y1> <X2> <Y2>$                            // 旧名：$a.椭圆描边$
$a.绘制椭圆 <X1> <Y1> <X2> <Y2>$                                // 旧名：$a.椭圆$
$a.绘制圆形描边 <X> <Y> <半径> <起始> <结束> <颜色>$             // 旧名：$a.圆形描边$
$a.绘制圆形 <X> <Y> <半径> <起始> <结束> <颜色>$                 // 旧名：$a.圆形$
$a.绘制多边形 <X1>,<Y1> <X2>,<Y2> <X3>,<Y3>...$                  // 旧名：$a.多边形$
$a.绘制多边形描边 <X1>,<Y1> <X2>,<Y2>...$                        // 旧名：$a.多边形描边$
$a.绘制随机线条 <数量>$                                          // 旧名：$a.随机线条$
$a.绘制随机点 <数量>$                                            // 旧名：$a.随机点$
// 在指定坐标绘制单个像素点
$a.绘制点 <X> <Y> <颜色>$                                        // 旧名：$a.点$
$a.绘制波浪 <X1> <Y1> <X2> <Y2> <波浪高度> <波长> <步长>$        // 旧名：$a.波浪$
// 打码像素块通过画笔大小调整，用法跟方形一样
$a.绘制马赛克 <X1> <Y1> <X2> <Y2>$                               // 旧名：$a.马赛克$
$a.高斯模糊 <X> <Y> <宽> <高>$                                   // 对指定区域做高斯模糊，无「绘制」前缀
$a.绘制圆弧 <X> <Y> <半径> <起始> <结束> <颜色>$                 // 旧名：$a.圆弧$
$a.绘制线 <X1> <Y1> <X2> <Y2> <颜色>$                            // 旧名：$a.线$
$a.绘制喷漆 <X1> <Y1> <X2> <Y2> <半径> <密度1~100> <颜色>$       // 旧名：$a.喷漆$
// 油漆桶填充，从指定坐标开始填充相邻的同色区域
$a.绘制油漆桶 <X> <Y> <颜色>$                                    // 旧名：$a.油漆桶$
$a.绘制文本 <X1> <Y1> <文本> <旋转|0.0> <颜色> <描边颜色> <描边宽度>$  // 旧名：$a.文本$
```

> 绘制类方法统一以「绘制」为前缀，旧名仍可用，作为兼容别名（见上方各行注释）；`$a.高斯模糊$` 是例外，没有「绘制」前缀。

画笔

```
// 只读取[私有]目录下，字体文件夹中字体文件
$a.字体 <文件路径|font.ttf>$
$a.大小 <大小>$
$a.设置颜色 <随机|#十六进制|颜色地址|R G B A>$
// 需要赋予值获取颜色数据（颜色获取不依赖画布，仍为全局函数）
颜色:$获取画笔颜色 <#十六进制|R G B A>$
```

画布重构，会绘制画布整体构造

```
// 旋转整个画布，背景会通过画笔颜色绘制
$a.旋转 <旋转>$
// 剪切画布，边缘会根据画笔颜色绘制
$a.圆角 <半径>$
// 给整个画布打码
$a.全图马赛克 <半径>$
// 将画布转为灰度图
$a.灰度$
```

> 画布相关的全局函数：`$创建画布 ...$`、`$获取画笔颜色 <#十六进制|R G B A>$`（颜色对象不依赖画布）、`$读图片 <文件路径>$`。注意 `$绘图 <JSON>$` 的参数是绘图 JSON 数据、不是画布对象，别写 `$绘图 画布$` 当输出。
