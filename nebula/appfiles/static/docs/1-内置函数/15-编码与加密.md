# 编码与加密

## AES

对称加密，密钥长度 16 / 24 / 32 字节（对应 AES-128 / AES-192 / AES-256）。

| 模式 | 安全性 | IV | 加密 / 解密 |
| ---- | ---- | ---- | ---- |
| **GCM**（推荐） | 高：认证加密，提供加密与完整性验证 | 自动生成，nonce 自动附加到密文 | `$AES_GCM加密 密钥 明文$` / `$AES_GCM解密 密钥 密文$` |
| **CTR** | 中：流加密，高效可并行，但不提供认证 | 需提供 16 字节 | `$AES_CTR加密 密钥 IV 明文$` / `$AES_CTR解密 密钥 IV 密文$` |
| **CBC** | 中：传统块加密，需要填充 | 需提供 16 字节 | `$AES_CBC加密 密钥 IV 明文$` / `$AES_CBC解密 密钥 IV 密文$` |
| **CFB**（已弃用） | 低：仅保留向后兼容，不推荐使用 | 需提供 16 字节 | `$AES_CFB加密 密钥 IV 明文$` / `$AES_CFB解密 密钥 IV 密文$` |

**IV 说明**：IV（初始化向量）必须与密钥一起保存；不同加密操作应使用不同的 IV。

## 摘要、编码与转换

| 函数 | 说明 |
| ---- | ---- |
| `$MD5编码 内容$` | MD5 |
| `$sha256 文本$` | SHA-256，返回 `[]byte` |
| `$B64编码 内容$` / `$B64解码 内容$` | Base64 |
| `$HTML编码 内容$` / `$HTML解码 内容$` | HTML 编码 / 解码 |
| `$URL编码 内容$` / `$URL解码 内容$` | 完全编码 |
| `$URL链接编码 url$` / `$URL链接解码 url$` | 只自动识别并编码 GET 参数，不会影响到链接本身 |
| `$Byte转String <Byte>$` / `$Byte生成 <文本>$` | 字节与文本互转 |
| `$哈基米加密 <文本> <密钥>$` / `$哈基米解密 <文本> <密钥>$` | 哈基米加解密，密钥可省略 |

### 字符编码

`$编码 <编码名> <内容>$` / `$解码 <编码名> <内容>$`

支持的编码名：GBK、二进制、十六进制、HZGB2312、GB18030、ASCII、ISO-8859-1。

```
$编码 二进制 你好$
$解码 二进制 111001001011110110100000111001011010010110111101$
```

## Ed25519

```
k:@$Ed25519生成密钥$->公钥
k:@$Ed25519从种子生成密钥 %密钥%$->私钥
```

| 函数 | 说明 |
| ---- | ---- |
| `$Ed25519种子大小$` | 获取种子长度 |
| `$Ed25519生成密钥$` | 生成一对公钥与私钥，返回 `map`（键为 `私钥` / `公钥`） |
| `$Ed25519从种子生成密钥 <密钥>$` | 从指定种子生成一对密钥，返回 `map`（键为 `私钥` / `公钥`） |
| `$Ed25519签名 <私钥> <消息>$` | 用私钥对消息签名，返回签名结果 |
| `$Ed25519验证签名 <公钥> <消息> <签名>$` | 验证签名是否合法，返回 true / false |
| `$Ed25519公钥转换为Curve25519 <公钥>$` | 公钥转换，返回 Curve25519 公钥 |
| `$Ed25519私钥转换为Curve25519 <私钥>$` | 私钥转换，返回 Curve25519 私钥 |
| `$Ed25519从Curve25519生成密钥 <Curve私钥>$` | 从 Curve25519 私钥生成 Ed25519 密钥，返回 `map`（键为 `私钥` / `公钥`） |

## RSA

非对称加密：公钥加密、私钥解密。

| 函数 | 说明 |
| ---- | ---- |
| `$RSA生成密钥$` / `$RSA生成密钥 2048$` | 生成 RSA 密钥对，返回 `map`（键为 `公钥` / `私钥`，均为 PEM 格式）；位数可省略，默认 2048 |
| `$RSA加密 <公钥> <明文>$` | 公钥加密，返回 base64 密文 |
| `$RSA解密 <私钥> <base64密文>$` | 私钥解密，返回明文 |
