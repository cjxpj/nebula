# 计算

> 支持运算符号

```
加 +
减 -
乘 *
除 /
```

> **`[...]` 是算术表达式**：支持括号与正常优先级（`[2*(1+1)]` = 4），**可以直接写进函数参数**里（值处替换 `$计算`）：
>
>     $延迟 [1000*%秒%]$              // 参数位置直接算
>     $写 a.txt 值 [%旧值%+1]$
>     $函数名 [%x%*2+%y%]$
>
> **`[...]` 内不要写空格**：函数参数是按空格切分的，`$延迟 [1000 * %秒%]$` 会被拆成 `[1000` / `*` / `%秒%]` 多个参数而报错，必须紧贴写成 `[1000*%秒%]`。
>
> 与 `$计算` 的区别：`$计算` 是函数（严格左到右、无括号、支持空格分隔的中文运算符），`[...]` 是嵌入在任意函数参数里的表达式（标准运算顺序）。`[...]` 内不能再嵌套 `$函数$`，需要函数结果时先 `变量:$函数$` 存好再用 `%变量%` 参与运算。

```
$计算 1 加 1$        // 加/减/乘/除 亦可用 + - * /
$计算 1 减 1$
$计算 1 乘 1$
$计算 1 除 1$
$计算 1 除余 1$      // 亦可用 %
$计算 1 按位或 1$    // 亦可用 |
$计算 1 左移 1$      // 亦可用 <<
$计算 1 右移 1$      // 亦可用 >>
$计算 1 根号 1$      // 平方根，亦可用 sqrt
$计算 1 四舍五入 1$
// 支持链式计算
$计算 1 + 2 + 3$
$计算 1 + 2 * 3$
$计算 10 除 2 加 3 乘 4$
```

> **`$计算` 严格从左到右求值，没有运算符优先级，也不支持括号**（实测）。先加后乘结果会整体偏移，括号会被当非法输入返回 `Error`：
>
>     $计算 1 + 2 * 3$      // 期望 7，实际 (1+2)*3 = 9
>     $计算 4 - 1 * 2$      // 期望 2，实际 (4-1)*2 = 6
>     $计算 1 + (2 * 3)$    // 期望 7，实际 Error（括号不支持）
>
> ✓ 正确样板（乘法写最前、加法收尾；减号项用 `0 -` 前置改写成加法）：
>
>     行2:$计算 %dx% * %步% + %行%$       // 行 + dx*步
>     行2:$计算 0 - %dx% * %步% + %行%$   // 行 - dx*步
>     总评分:$计算 %防守评分% * 0.9 + %评分%$   // 评分 + 防守*0.9
>
> 需要标准运算顺序（含括号、优先级）时改用 `[...]` 算术表达式（见上方），不要用 `$计算`。
