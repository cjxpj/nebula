# 全局数据库

## data.db 键值存储

> 程序内置全局 SQLite 数据库 `NebulaData/database/data.db`，无需手动打开连接。
>
> **适用场景**：`db_*` 适合需要跨词库共享、余额/排行、多账号统计等关系型数据。若只是存取简单键值数据（个人背包、进度、配置等），**优先用文件读写** `$读 路径 键 默认值$` / `$写 路径 键 数据$`（见「内置函数 → 文件操作」），更直观且不依赖数据库。

```
// 写入（2参数时 data 存空字符串），与 写sqlite 一致固定写入 fs_files 表；首参数为命名空间，实际 key 为「命名空间/key」
$db_写 <命名空间> <key> <data>$
$db_写 <命名空间> <key>$
// 读取（1参数获取该命名空间全部key，2参数获取值，3参数获取值+默认值）
$db_读 <命名空间>$
$db_读 <命名空间> <key>$
$db_读 <命名空间> <key> <默认值>$
// 删除表记录
$db_删除 <表名> <key>$
$db_删除文件 <key>$    // 删除 fs_files 表中记录
$db_删除文件夹 <key>$  // 删除 fs_files 表中记录
```

## money 表（经济系统）

> 内置 `money` 表，以 `类型 + 账号` 作为联合主键（索引），余额为整数，未存在的账号余额视为 0。

- **数值类型**：仅支持整数，**不支持小数**（传入小数会被解析为 0）。
- **存储上限**：余额为 SQLite `INTEGER`（Go `int64`），范围 `-9223372036854775808 ~ 9223372036854775807`（约 ±922 京），超出会溢出。
- **负数**：`db_设置` 支持设为负数；`db_减少` 可减到负数。

```
// 增加余额，返回操作后的余额
$db_添加 <类型> <账号> <整数>$
// 减少余额，返回操作后的余额
$db_减少 <类型> <账号> <整数>$
// 直接设置余额（可为负数），返回操作后的余额
$db_设置 <类型> <账号> <整数或负数>$
// 查询余额：账号留空返回 {} 数据（账号->余额），否则返回 {"余额":...,"排名":...}
$db_查询 <类型>$
$db_查询 <类型> <账号>$
// 查询排名：按余额降序返回；页数留空返回全部列表，页数默认 1，显示数量默认 10
$db_查询排名 <类型>$
$db_查询排名 <类型> <页数>$
$db_查询排名 <类型> <页数> <显示数量>$
// 清空经济系统：类型留空清空整个 money 表，否则只清空该类型
$db_清空经济系统$
$db_清空经济系统 <类型>$
```

`$db_查询排名$` 返回 JSON 数组（按余额降序，`排名` 为全局名次，翻页时从上一页末位续排）：

```json
[{"排名":1,"账号":"用户A","余额":100}]
```
