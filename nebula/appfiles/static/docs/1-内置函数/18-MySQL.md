# MySQL

`$新建mysql$` 返回「MySQL 连接对象」（面对像，惰性连接，创建时不会立即连接），后续通过 `$对象.方法$` 操作。

```
连接:$新建mysql <账号> <密码> <地址[:端口]>$   // 地址支持 host 或 host:端口，端口默认 3306
连接:$新建mysql root 941331b62d54a7f7 172.20.167.249:3307$
$连接.PING$                                   // 检测连接，返回 "true" / "false"
$连接.切换数据库 数据库名称$                    // 切换默认库，后续写/读/删除操作使用该库
sql::CREATE DATABASE 数据库名称;
$连接.执行 %sql%$                              // 执行 SQL，返回下方 JSON；带数据库名的 SQL 会自动记住该库
sql::INSERT INTO 表 (name, data) VALUES (?, ?)
$连接.执行 数据库名称 %sql% 绑定内容1 绑定内容2$  // 参数依次绑定 SQL 中的 ? 占位符
$连接.写 表单 键 值$                            // 快捷读写，需先切换数据库或执行过带数据库名的 SQL
$连接.读$                                      // 获取全部表单（JSON 数组）
$连接.读 表单$                                 // 获取全部键（JSON 数组）
$连接.读 表单 键$                              // 读取值
$连接.读 表单 键 默认值$                        // 读取，不存在返回默认值
$连接.删除文件 键$                             // 删除 fs_files 表中记录
$连接.删除文件夹 键$                           // 删除 fs_files 表中记录
$连接.关闭$                                    // 关闭连接，返回 "true"
```

`$连接.执行$` 返回 JSON 结构（`data` 仅查询语句返回，为结果行数组；`rows_affected` / `last_insert_id` 仅非查询语句返回）：

```json
{
  "error": "",
  "last_insert_id": 0,
  "rows_affected": 1,
  "data": [{"列名":"值"}]
}
```
