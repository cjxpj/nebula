# 邮件操作

`$创建邮件$` 返回一个「邮件对象」（面对像），后续通过 `$对象.方法$` 发送邮件。

| 调用 | 说明 |
| ---- | ---- |
| `$创建邮件 <链接> <端口> <账号> <密码> [昵称]$` | 创建邮件连接；昵称可选，不填则收件人只看到邮箱地址 |
| `$a.设置昵称 <昵称>$` | 设置发件人昵称（可选，设置后收件人看到的是昵称而不是邮箱地址） |
| `$a.发送 <收件人> <标题> <内容>$` | 发送纯文本邮件，发送成功返回 `"true"`、失败返回错误信息；多收件人用逗号分隔（如 `a@qq.com,b@qq.com`） |
| `$a.发送HTML <收件人> <标题> <HTML内容>$` | 发送 HTML 邮件 |

样板（QQ 邮箱 smtp.qq.com 587）：

```
// 纯文本邮件
a:$创建邮件 smtp.qq.com 587 2960965389@qq.com xxxxx$
$a.发送 2960965389@qq.com 测试标题 这是一封测试邮件$

// 自定义发件人昵称（创建时直接填写第五个参数）
a:$创建邮件 smtp.qq.com 587 2960965389@qq.com xxxxx 星云机器人$
$a.发送 2960965389@qq.com 测试标题 这是一封测试邮件$

// 也可以创建后再设置昵称
a:$创建邮件 smtp.qq.com 587 2960965389@qq.com xxxxx$
$a.设置昵称 星云机器人$
$a.发送 2960965389@qq.com 测试标题 这是一封测试邮件$

// HTML邮件
a:$创建邮件 smtp.qq.com 587 2960965389@qq.com xxxxx$
$a.发送HTML 2960965389@qq.com 通知 <h1>你好</h1><p>这是一封HTML邮件</p>$
```
