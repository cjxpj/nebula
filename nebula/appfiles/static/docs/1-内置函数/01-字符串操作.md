# 字符串操作

## 大小写字母

```
$大写字母 a$
$小写字母 A$
```

## 字符拼接

```
$字符拼接 & ["url=","msg="]$
```

## 替换

`$替换 <文本> <需替换> <替换后> <次数>$`，次数留空为替换全部；如 `$替换 11234 1 2 1$` 返回 21234。

```
$替换 替换内容 需要替换 替换后 <次数>$
```

### 正则替换

```
$正则替换 文本 正则 替换后 <次数>$
$正则替换 A1A123A \d+ %a%$
```

## 截取

参数 2 是起始位置（从 0 计，必须为数字），参数 3 是截取长度（**可留空**，留空 = 截到字符串末尾；超出剩余长度时同样截到末尾，不会越界报错）。

```
$截取 abcd 1 2$     // "bc"
$截取 abcd 1$       // "bcd"
$截取 abcd 1 999$   // "bcd"
```

## 取中间

```
$取中间 abcd a c$
```

## 字符定位

没有找到会返回 -1

```
$查找字 内容 查找内容$
```

## 字符切片

```
$字符切片 内容$      // 返回[]json
```

## 去除多余符号

```
$去除左右 文本 符号$
$去除左 文本 符号$
$去除右 文本 符号$
```

## 长度

文本长度是单字符算作1单位

```
$文本长度 内容$
$长度 内容$
```

## 取前字符/取后字符

```
$取前字符 <数量> <文本>$
$取后字符 <数量> <文本>$
```

## 复读

```
$复读 <文本> <次数>$
```

## 数字转中文

```
$数字转中文 <数字>$
```

## 数字格式化

格式化数字，支持 `b`/`e`/`E`/`f`/`g`/`G` 格式（默认 `f`）。

```
$数字格式化 <数字> <小数位数> <格式>$
$数字格式化 1234.5678 2$
$数字格式化 255 2 b$    // 二进制
```

## 四舍五入

```
$四舍五入 <数字> <小数位数>$
$四舍五入 3.14159 2$    // 返回 3.14
```

## 炫酷文字

生成 ASCII 艺术字（figlet 字体），可用于生成 LOGO 文字。`<字体>` 为 figlet 字体名，可省略，默认 `standard`，可选如 `slant`、`big`、`banner`、`shadow` 等。

```
$炫酷文字 <文本> <字体>$
$炫酷文字 CJXPJ$
```

返回：

```
   ____       _  __  __  ____        _
  / ___|     | | \ \/ / |  _ \      | |
 | |      _  | |  \  /  | |_) |  _  | |
 | |___  | |_| |  /  \  |  __/  | |_| |
  \____|  \___/  /_/\_\ |_|      \___/
```

## 中文转拼音

可以获取多音字，数字代表声调。

```
$中文转拼音 了$
```

返回示例 `[["le","lia3o","lia4o"]]`
