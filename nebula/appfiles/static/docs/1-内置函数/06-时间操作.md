# 时间操作

## 时间变量

```
%时间戳%
%毫秒时间戳%
%纳秒时间戳%
%时间yyyy%
```

## 时间戳转时间

```
$时间戳转时间 %时间戳%$   // 秒级时间戳转时间字符串，不传格式时默认 yyyy-MM-dd HH:mm:ss
$时间戳转时间 %时间戳% "yyyy-MM-dd HH:mm:ss"$  // 自定义格式
```

## 时间转时间戳

```
$时间转时间戳 "2026-08-22 10:30:00"$   // 时间字符串转秒级时间戳，不传格式时自动识别常见格式（含 ISO8601）
$时间转时间戳 "2026/08/22 10:30:00" "yyyy/MM/dd HH:mm:ss"$ // 自定义格式
```

## 延迟

```
$延迟 [1000*1]$   // 毫秒单位，示例为延迟 1 秒
```

## 时间间隔

```
开始:$时间戳$
// ... 执行一些操作
$时间间隔 <开始>$  // 计算两个时间点之间的间隔，返回间隔时间
```
