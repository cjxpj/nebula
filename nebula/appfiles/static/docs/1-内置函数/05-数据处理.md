# 数据处理

## JSON 操作

```
$JSON解析 <json> <键>$
// 存可以改成存字只存文本数据
// 可以直接通过多层键设置值
$JSON存 <json> <键>... <值>$
// $JSON存 {} a b 内容$ 返回 {"a"{"b":"内容"}}
$JSON存字 <json> <键>... <值>$
// 这是给元素追加用的
$JSON追加 <json> <值>$
$JSON追加字 <json> <值>$
$JSON存在 <json> <键>$
$JSON删 <json> <键>$
```

> **`$JSON解析` 一次只取一层**（键可写 `->` 路径批量解析）。取嵌套值要分步：`$JSON解析 %棋盘% 行索引$` 得到行数组，再 `$JSON解析 %行% 列索引$`；写成三个参数会报 `参数数量错误`。
>
> **`$JSON删` / `$JSON存` 等「返回新 JSON」的函数必须把返回值赋给变量**，原变量不会被就地修改（实测）：`$JSON删 %背包% 草鱼$` 返回值被丢弃、删除不生效，须写成 `背包:$JSON删 %背包% 草鱼$`。
>
> **`$JSON存` 写嵌套值时键路径必须写全**，漏写中间键是整体替换而非追加：✗ `新棋盘:$JSON存 %棋盘% board %行数组%$` 会把 15×15 棋盘的 `board` 换成一行扁平数组、其余 14 行全部丢失。✓ 正确流程：
>
>     行数组:$JSON解析 %棋盘% board %行%$      // 1. 取出要改的子层
>     行数组:$JSON存 %行数组% %列% 1$          // 2. 修改子层元素
>     棋盘:$JSON存 %棋盘% board %行% %行数组%$  // 3. 完整键路径写回
>
>
> **`$函数$` 必须成对闭合**，漏写闭合 `$` 该调用不执行、赋值落空，表现为「静默不生效、输出为空」；写完检查行内 `$` 数量为偶数。

| 需求 | 返回 |

```
// 快捷解析支持->批量解析
$JSON解析 <json> 键->键$

```

### JSON全部键

获取对象或数组的全部键，返回 JSON 数组。

```
$JSON全部键 <json>$
// $JSON全部键 {"b":1,"a":2}$ 返回 ["a","b"]（键按字母排序）
// $JSON全部键 ["x","y","z"]$ 返回 [0,1,2]
```

### JSON美化

第二个参数是**缩进字符串**，原样作为每层缩进前缀，**不是空格数量**：传 `1` 得到字面 `1` 缩进、传 `"  "`（带引号的两个空格）才得到空格缩进。默认（可留空）是两空格。

```
$JSON美化 <json> <缩进字符串>?$
```

### JSON重名解析

支持重名 key 解析、数组按索引或键值对匹配查询。

```
$JSON重名解析 {"a":{"b":1}} a->b$      // 普通对象解析（等同 JSON解析）→ 1
$JSON重名解析 {"a":"b","a":"c"} a$     // 重名 key 合并为数组 → ["b","c"]；a->0 取首项 → "b"
$JSON重名解析 [{"name":"Alice","age":20},{"name":"Bob","age":30}] 0->age$         // 数字开头按索引 → 20
$JSON重名解析 [{"name":"Alice","age":20},{"name":"Bob","age":30}] name->Bob->age$ // 非数字开头按键值对匹配 → 30
```

### JSON赋予值

> **块内内容是原样 JSON**：键必须带引号（`"键":值`），值里的 `%变量%` 要写在**引号内**（`"键":"%变量%"`），整段值只有 `%变量%` 时会按类型填入；**裸写 `%变量%` 会让整块解析失败返回 error**。行内缩进、逗号后的空格都没问题。**块内 `$函数$` 不会执行**，残留的 `$...$` 是非法 JSON 字符，同样会让整块返回 error——需要函数结果请先 `变量:$函数$` 存起来再在块内 `%变量%` 引用。

```
a:123
a:{ "a":"a", "b": "%a", "c": "s%a" }
```

### JSON框（`JSON>` 键=值形式）

与上面 `变量:{`/`变量:[`（原样 JSON）不同，`JSON>` 框按**键=值**设置项逐行构建对象/数组，键支持 `->` 多层路径：

```
JSON>赋予值={}
a=b
a->a=b
<JSON
```

> 关键规则（实测）：
> - 开启行写死 `JSON>变量={}` / `JSON>[]`，**后面不要再单独写 `}` / `]` 行**，直接跟键=值行，以 `<JSON` 闭合；
> - 键=值行**行尾不能带逗号**——尾逗号会让整块静默失效、无任何输出；
> - `键=值`：值按**文本**存入（`棋盘=%棋盘%` 会存成字符串 `"[[0,1],[1,0]]"`）；
> - `键:=值`：值**保留类型**（数字仍为数字、JSON 数组/对象原样嵌入），需要嵌入数组/数字时用 `:=`：`棋盘:=%棋盘%` → `{"棋盘":[[0,1],[1,0]]}`；
> - 块的结果直接作为该行的输出，也可在块后 `%变量%` 读取。

### JSON查找文本

在JSON数组或对象中查找匹配的值，返回键名或索引。

```
$JSON查找文本 <json> <搜索文本>$
// 精确匹配，返回键名(对象)或索引(数组)，未找到返回-1；例：$JSON查找文本 {"苹果":"水果","香蕉":"水果"} 水果$ 返回 "苹果"
$JSON模糊查找文本 <json> <搜索文本>$
// 包含匹配，只要值包含目标文本即返回；例：$JSON模糊查找文本 {"a":"红苹果","b":"青苹果"} 苹果$ 返回 "a"
$JSON正则查找文本 <json> <正则表达式>$
// 正则匹配；例：$JSON正则查找文本 {"a":"abc123","b":"456def"} ^[a-z]+$ 返回 "a"
```

### JSON拆分

将数组按 N 个元素一组拆分，或将对象按 N 个键值对一组拆分，返回子元素数组。

```
$JSON拆分 <json> <数量>$
// $JSON拆分 [1,2,3,4] 2$ 返回 [[1,2],[3,4]]
// $JSON拆分 {"a":"","b":"","c":"","d":""} 2$ 返回 [{"a":"","b":""},{"c":"","d":""}]
```

## 范围

```
$范围 5 10$   // 生成范围内元素，返回 [5,6,7,8,9,10]
```

## 排序

```
$排序 键 数据 true/false$   // true/false 代表正反排序
// 示例：z 为 JSON 数组，按 data 正序排序
z:[{"data":"100","key":"啤酒"},{"data":"500","key":"兄弟"},{"data":"500","key":"兄弟"},{"data":"50","key":"你好香"}]
$排序 data %z% true$
```

## 分割

```
$分割 , a,b,c$
$分割 , a,b,c 2$   // 分割范围
```

## 分割匹配

```
$分割匹配 <分隔符> <文本> <匹配文本>$   // 判断文本按分隔符分割后是否包含指定值，返回 true / false
$分割匹配 , a,b,c b$    // 返回 true
$分割匹配 , a,b,c d$    // 返回 false
```
