# 数据库

## MySQL

`$新建mysql$` 返回「MySQL 连接对象」（面对像，惰性连接，创建时不会立即连接），后续通过 `$对象.方法$` 操作。

```
连接:$新建mysql <账号> <密码> <地址[:端口]>$   // 地址支持 host 或 host:端口，端口默认 3306
连接:$新建mysql root 941331b62d54a7f7 172.20.167.249:3307$
$连接.PING$                                   // 检测连接，返回 "true" / "false"
$连接.切换数据库 数据库名称$                    // 切换默认库，后续写/读/删除操作使用该库
sql::CREATE DATABASE 数据库名称;
$连接.执行 %sql%$                              // 执行 SQL，返回下方 JSON；带数据库名的 SQL 会自动记住该库
sql::INSERT INTO 表 (name, data) VALUES (?, ?)
$连接.执行 数据库名称 %sql% 绑定内容1 绑定内容2$  // 参数依次绑定 SQL 中的 ? 占位符
$连接.写 表单 键 值$                            // 快捷读写，需先切换数据库或执行过带数据库名的 SQL
$连接.读$                                      // 获取全部表单（JSON 数组）
$连接.读 表单$                                 // 获取全部键（JSON 数组）
$连接.读 表单 键$                              // 读取值
$连接.读 表单 键 默认值$                        // 读取，不存在返回默认值
$连接.删除文件 键$                             // 删除 fs_files 表中记录
$连接.删除文件夹 键$                           // 删除 fs_files 表中记录
$连接.关闭$                                    // 关闭连接，返回 "true"
```

`$连接.执行$` 返回 JSON 结构（`data` 仅查询语句返回，为结果行数组；`rows_affected` / `last_insert_id` 仅非查询语句返回）：

```json
{
  "error": "",
  "last_insert_id": 0,
  "rows_affected": 1,
  "data": [{"列名":"值"}]
}
```

## SQLite

`$打开sqlite$` 返回「SQLite 连接对象」（面对像），后续通过 `$对象.方法$` 操作，文件记得使用 `.db` 后缀。

```
连接:$打开sqlite <文件|:内存:> <默认值>$    // 文件为空或 :内存: 表示内存数据库；打开失败返回第 2 个参数默认值
连接:$打开sqlite database/data.db$
连接:$打开sqlite :内存:$
$连接.写 <表单> <键> <值>$
$连接.读$                        // 获取全部表单（JSON 数组）
$连接.读 <表单>$                  // 获取全部键（JSON 数组）
$连接.读 <表单> <键>$             // 读取值
$连接.读 <表单> <键> <默认值>$     // 读取，不存在返回默认值
$连接.删除文件 <key>$             // 删除 fs_files 表中记录
$连接.删除文件夹 <key>$           // 删除 fs_files 表中记录
$连接.执行 <sql> <绑定参数>...$    // 执行 SQL，返回 JSON，结构同 MySQL
$连接.关闭$                       // 返回 "true" / "false"
```

执行语句示例

```
查询语句
c:"""
SELECT name, email FROM users
"""
$连接.执行 %c%$

插入语句
b:"""
INSERT INTO users (name, email) VALUES (?, ?)
"""
$连接.执行 %b% a b$

创建表语句
a:"""
CREATE TABLE IF NOT EXISTS users (
	name TEXT NOT NULL,
	email TEXT NOT NULL UNIQUE
)
"""
$连接.执行 %a%$
```

快捷读写（无需手动打开连接，默认在 fs_files 表单下读写）

```
$读sqlite <文件> <键> <默认值>$
$读sqlite <文件>$        // 获取全部键
$写sqlite <文件> <键> <值>$
```

## 全局数据库 data.db

> 程序内置全局 SQLite 数据库 `NebulaData/database/data.db`，无需手动打开连接。
>
> **适用场景**：`db_*` 适合需要跨词库共享、余额/排行、多账号统计等关系型数据。若只是存取简单键值数据（个人背包、进度、配置等），**优先用文件读写** `$读 路径 键 默认值$` / `$写 路径 键 数据$`（见「内置函数 → 文件操作」），更直观且不依赖数据库。

```
// 写入（2参数时 data 存空字符串），与 写sqlite 一致固定写入 fs_files 表；首参数为命名空间，实际 key 为「命名空间/key」
$db_写 <命名空间> <key> <data>$
$db_写 <命名空间> <key>$
// 读取（1参数获取该命名空间全部key，2参数获取值，3参数获取值+默认值）
$db_读 <命名空间>$
$db_读 <命名空间> <key>$
$db_读 <命名空间> <key> <默认值>$
// 删除表记录
$db_删除 <表名> <key>$
$db_删除文件 <key>$    // 删除 fs_files 表中记录
$db_删除文件夹 <key>$  // 删除 fs_files 表中记录
```

## 全局数据库 money 表（经济系统）

> 内置 `money` 表，以 `类型 + 账号` 作为联合主键（索引），余额为整数，未存在的账号余额视为 0。

- **数值类型**：仅支持整数，**不支持小数**（传入小数会被解析为 0）。
- **存储上限**：余额为 SQLite `INTEGER`（Go `int64`），范围 `-9223372036854775808 ~ 9223372036854775807`（约 ±922 京），超出会溢出。
- **负数**：`db_设置` 支持设为负数；`db_减少` 可减到负数。

```
// 增加余额，返回操作后的余额
$db_添加 <类型> <账号> <整数>$
// 减少余额，返回操作后的余额
$db_减少 <类型> <账号> <整数>$
// 直接设置余额（可为负数），返回操作后的余额
$db_设置 <类型> <账号> <整数或负数>$
// 查询余额：账号留空返回 {} 数据（账号->余额），否则返回 {"余额":...,"排名":...}
$db_查询 <类型>$
$db_查询 <类型> <账号>$
// 查询排名：按余额降序返回；页数留空返回全部列表，页数默认 1，显示数量默认 10
$db_查询排名 <类型>$
$db_查询排名 <类型> <页数>$
$db_查询排名 <类型> <页数> <显示数量>$
// 清空经济系统：类型留空清空整个 money 表，否则只清空该类型
$db_清空经济系统$
$db_清空经济系统 <类型>$
```

`$db_查询排名$` 返回 JSON 数组（按余额降序，`排名` 为全局名次，翻页时从上一页末位续排）：

```json
[{"排名":1,"账号":"用户A","余额":100}]
```
