# 文件结构

## 两段结构：头部 + 正文词条

.n 是 UTF-8 文本，全文分两段：

| 段 | 范围 | 内容 |
| --- | --- | --- |
| 头部 | 文件开头 → 第一个空行 | 中间件：`$引入`、`//@资源`、`$重定向触发词`、初始化赋值等，每次执行都会经过 |
| 正文词条 | 第一个空行之后 | 触发词 + 紧接其下的正文行 |

- 全文没有任何空行时，看首个有效行（跳过空行与普通注释）：是赋值 / `$引入` / 预编译指令 / 函数调用（如 `$执行词库 ...$`、`$重定向触发词 ...$`）/ 框开启行（`循环>`、`遍历>`、`如果>`、`匹配>`、`文本>`、`JSON>` 等）→ 整篇按头部脚本执行、不产生词条（适合只做初始化的词库）；否则整篇按正文词条解析，首个有效行就是触发词。
- **头部的首行（也就是文件第一行）同样算中间件、会被执行**；头部与它下面的第一个词条之间要用一个空行分隔。
- `$设置工作目录 ...$` 用于确定数据目录，建议只在启动词库 `start.n` 的 `[f]_初始化` 或头部调用一次；`$设置系统变量 名 值$` 用于设置引擎系统级变量（如 `日志目录`、`终端词库路径`），同样只在启动词库调用。

## 中间件：头部 与 `[f]_中间件` 二选一

两者等价，都是「每次执行都会经过」的中间件。

- 只写头部 → 头部内容即中间件；只写 `[f]_中间件` → 函数内容即中间件。
- 同时写时 `[f]_中间件` 覆盖头部（头部里的运行时语句被忽略，但 `$引入`、`//@资源` 等预编译指令仍生效），并产生一条「覆盖」警告，提醒你只保留一种写法。
- 需要「首次加载只执行一次」的逻辑，用 `[f]_初始化` 定义。
- `_初始化` / `_中间件` 是保留生命周期钩子，由引擎自动调用，**不能用 `$函数名$` 手动调用**。

## 词条

一条词条 = 触发词独占一行 + 紧接其下的正文行。

- 触发词 / `[函数]` 块上方必须有一个空行，与头部或上一条词条分隔；缺了空行，它会贴进上一条正文而完全失效（文件里第一个词条就是触发词、即没有头部时，文件开头也要留一个空行）。
- 正文行之间必须紧贴、不能有空行：空行会立即结束该词条，把后续内容拆成一堆没有触发词的空词条。.n 不是普通脚本，禁止「无触发词、逐行罗列、行间留空行」的写法——写进文件的每一段代码都必须能归属到某个触发词之下。
- 正文若要包含空行，整条需改写为下面两种写法之一：触发词行尾加 ` #{`、正文以单独一行 `}#` 结束；或触发词正文以 `<?n` 开始、`?>` 结束（`<?n`、`?>` 各占一行）。
- 注释放置、缩进、换行等其他书写规则见《07-注释与换行》。

## 头部预编译指令（只写在头部，写在正文不生效）

| 指令 | 作用 |
| --- | --- |
| `$引入 xxx.n$`、`$引入 dic/*$` | 引入私有目录下的词库文件 / 目录 |
| `$引入 @QQBot$`、`$引入 @NapCat$` | 引入机器人函数（可多行引入多个）。调用机器人「主动发送函数」前必须先引入对应机器人；回复函数由框架自动注入、无需引入 |
| `变量:$引入 目标$` | 把目标里的全部函数打包成实例赋给变量，之后用 `$变量.方法 参数$` 调用（赋予值形式只能用 `$引入`，不支持 `变量:#引入=目标`） |
| `#引入=目标` | `$引入 目标$` 的等价旧写法，仅限非赋予值形式（推荐用 `$引入`） |
| `//@资源` | 单独占一行，下一行紧跟一个「变量名:文件路径」（一个 `//@资源` 配一个变量）；编译期把文件内容读入变量，用 `%变量名%` 引用 |
| `//@一次性资源` | 用法与 `//@资源` 相同，但变量读取一次后即销毁 |

## 引入与资源只能读「私有」目录

上表所有写法都**只能读取私有目录内的文件**，不能读取其它任意位置。

- 「私有」的位置：宿主（Nebula 网站 / 机器人平台）下是每个账号根目录下的固定目录（与 `词库`、`储存`、`网站词库` 并列，账号之间互相隔离）；引擎独立运行时即应用数据目录下的 `private/`。
- 路径相对「当前词库所属账号的私有目录」解析，可写子目录（如 `$引入 dic/工具.n$`）。
- 禁止绝对路径与 `../` 越界：越界会直接报错「引入目标越界（须在私有目录内）」，符号链接也不允许逃逸出私有目录。

## 完整示例

头部内不能有空行，第一个空行之前都属于头部：

```n
// ===== 头部（文件开头到第一个空行之前）=====

// ① 引入指令：本地文件 / 目录 / 机器人（本地文件只能来自私有目录）
$引入 工具函数.n$          // 引入 私有/工具函数.n 的全部函数
$引入 dic/*$              // 引入 私有/dic/ 目录下全部 .n 词库
$引入 @QQBot$             // 引入 QQ 官方机器人（回复 + 主动发送函数）
$引入 @NapCat$            // 引入 NapCat 机器人函数
$引入 @FeiShu$            // 引入飞书机器人函数

// ② 赋予值形式：把整个包打包成实例赋给变量（只能用 $引入，不能用 #引入=）
甲:$引入 我的包$           // 私有/我的包.n 的全部函数 → 实例「甲」
                         // 之后用 $甲.方法 参数$ 调用，如 $甲.读取变量$

// ③ 旧写法（仅非赋予值形式可用）：#引入=工具函数.n 等价于 $引入 工具函数.n$

// ④ 编译期资源：一个 //@资源 配一个「变量名:文件路径」，指令与变量之间不能有空行
//@资源
配置:config.txt           // %配置% = 私有/config.txt 的文本内容
//@资源
模板:模板.html            // %模板% = 私有/模板.html 的文本内容
//@一次性资源
令牌:token.txt            // %令牌% 只在本次执行有效

// ⑤ 普通初始化赋值（每次执行都会经过，作为中间件）
默认名:访客

// ===== 第一个空行结束头部，下面是正文词条 =====
Main
你好，%默认名%！配置：%配置%
```
