# 文件结构

1. .n 是 UTF-8 文本，全文分「头部」与「正文词条」两段：文件开头到第一个空行为止是头部（一般只放 $引入 xxx.n$、初始化赋值、$重定向触发词 ...$ 等），空行之后全部是词条；若全文没有任何空行，则看首个有效行（跳过空行与普通注释）——是赋值 / $引入 / 预编译指令 / 函数调用（如 $执行词库 ...$、$重定向触发词 ...$）或框开启行（循环>、遍历>、如果>、匹配>、文本>、JSON> 等）时，整篇按头部初始化脚本执行（不产生任何词条，适合只做初始化的词库）；否则按正文词条解析（首个有效行作为触发词）；$设置工作目录 ...$ 用于确定数据目录，建议只在启动词库 start.n 的初始化（`[f]_初始化`）或头部调用一次；
2. 头部是「每次执行都会经过」的中间件（类似其他语言的中间件），写在这里的初始化赋值、$重定向触发词$ 等每次都执行；`[f]_中间件` 是与头部等价的函数写法，二者是中间件的两种写法、二选一——只写头部时头部内容即中间件，只写 `[f]_中间件` 时函数内容即中间件；若同时写，`[f]_中间件` 覆盖头部（头部运行时语句被忽略，但 $引入、//@资源 等预编译指令仍生效），并产生一条「覆盖」警告提醒你只保留一种写法。需要「首次加载只执行一次」的逻辑，用 `[f]_初始化` 定义。`_初始化` / `_中间件` 是保留生命周期钩子，由引擎自动调用，不能用 `$函数名$` 手动调用；
3. 一条词条 = 触发词独占一行 + 紧接其下的正文行，正文行之间必须紧贴、不能有空行（空行会立即结束该词条，把后续内容拆成一堆没有触发词的空词条）；.n 不是普通脚本，禁止「无触发词、逐行罗列、行间留空行」的写法，写进文件的每一段代码都必须能归属到某个触发词之下；
4. 正文若要包含空行，整条需改写为「触发词 #{ ... }#」（触发词行尾加 ` #{`，正文以单独一行 `}#` 结束）或「触发词正文以 `<?n` 开始、`?>` 结束」（`<?n`、`?>` 各占一行），只有这两种写法允许块内空行；
5. 头部常见预编译指令（只写在头部，写在正文不生效）：$引入 xxx.n$、$引入 dic/*$ 引入本地词库文件 / 目录，$引入 @QQBot$、$引入 @NapCat$ 引入机器人函数（可多行引入多个；要调用机器人「主动发送函数」前必须先引入对应机器人，回复函数由框架自动注入、无需引入）；变量:$引入 目标$ 把目标里的全部函数打包成实例赋给变量，之后用 $变量.方法 参数$ 调用（赋予值形式只能用 $引入 函数写法，不支持 变量:#引入=目标）；#引入=目标 是 $引入 目标$ 的等价旧写法，二者效果相同（仅限非赋予值形式，推荐用 $引入）；//@资源 单独占一行、下一行紧跟一个「变量名:文件路径」（一个 //@资源 配一个变量），编译期把文件内容读入变量（用 %变量名% 引用，路径相对应用数据目录 private/），//@一次性资源 用法相同但变量读取一次后即销毁。

一个完整的头部示例（头部内不能有空行，第一个空行之前都属于头部）：

```n
// ===== 头部（文件开头到第一个空行之前）=====

// ① 引入指令：本地文件 / 目录 / 机器人
$引入 工具函数.n$          // 引入 private/工具函数.n 的全部函数
$引入 dic/*$              // 引入 private/dic/ 目录下全部 .n 词库
$引入 @QQBot$             // 引入 QQ 官方机器人（回复 + 主动发送函数）
$引入 @NapCat$            // 引入 NapCat 机器人函数
$引入 @FeiShu$            // 引入飞书机器人函数

// ② 赋予值形式：把整个包打包成实例赋给变量（只能用 $引入，不能用 #引入=）
甲:$引入 我的包$           // private/我的包.n 的全部函数 → 实例「甲」
                         // 之后用 $甲.方法 参数$ 调用，如 $甲.读取变量$

// ③ 旧写法（仅非赋予值形式可用）：#引入=工具函数.n 等价于 $引入 工具函数.n$

// ④ 编译期资源：一个 //@资源 配一个「变量名:文件路径」，指令与变量之间不能有空行
//@资源
配置:config.txt           // %配置% = private/config.txt 的文本内容
//@资源
模板:模板.html            // %模板% = private/模板.html 的文本内容
//@一次性资源
令牌:token.txt            // %令牌% 只在本次执行有效

// ⑤ 普通初始化赋值（每次执行都会经过，作为中间件）
默认名:访客

// ===== 第一个空行结束头部，下面是正文词条 =====
Main
你好，%默认名%！配置：%配置%
```
