# 变量

## 赋值与读取

| 写法 | 含义 |
| --- | --- |
| `变量名:值` | 赋值（变量名裸写、不带 `%`）；空值写 `变量名:`（冒号后直接留空） |
| `变量+:值` | 同名追加 / 数值自增 |
| `变量-:值` | 数值自减 |
| `变量::值` | 原样文本赋值：值不做 `%变量%` / `$函数$` 解析 |
| `%变量名%` | 读取（只有读取才带 `%`） |

- 赋值行里把变量名写成 `%变量名%:` **无效**：整行会被当普通文本输出、变量根本没生成，之后读 `%变量名%` 会报「变量不存在」。
- 函数调用 `$函数 参数$` 会**就地返回结果**：只需要输出就直接写一行 `$函数 参数$`；只有结果还要复用（再输出、当参数、参与运算、写进文本块）时才赋值存起来。

## 没有字符串字面量

本语言没有字符串字面量类型。`变量名:""` 不会得到空值，而是把两个引号当普通字符存进变量，后续输出 / 拼接 / 渲染都会带着这两个引号（例如网页词库写 `九宫格HTML:""`，页面会直接显示 `""`）。要空值就写 `变量名:`；需要重新累计的变量一律这样初始化（如 `计数:` 再 `计数+:1`）。

## 取值

- 读 JSON 路径用 `%@变量.键.键%`。
- 三目与回退**只在赋值中生效**：`条件?真值:假值`、`值?:回退值`。

## 计算：先取中间变量

- 算术与计算必须「先取中间变量、再参与运算」：函数参数里、`[...]` 算术表达式里都**不能再嵌套 `$函数$`**。
  - ✗ `$JSON存 %背包% 草鱼 %$JSON解析 ...$ + 1$`、`$延迟 [1000*$随机数 1 3$]$`
  - ✓ 先 `旧数量:$JSON解析 %背包% 草鱼$`、`秒:$随机数 1 3$`，再 `$JSON存 %背包% 草鱼 $计算 %旧数量% + 1$$`、`$延迟 [1000*%秒%]$`
- `[...]` 内不要写空格（函数参数按空格切分）：写 `[1000*%秒%]`，不写 `[1000 * %秒%]`。

## 命名与作用域

- 变量名不超过 32 字节；变量名、触发词、函数名都用有意义的中文或英文。
- 跨函数读写用 `$全局变量 名 值$` / `$全局变量 名$`；线程级用 `$线程变量$`。
- `_` 开头结尾的名字保留给系统魔术变量（自动注入、无需赋值，不要自己占用）：`%__词库路径__%`（当前执行的词库文件路径）、`%_继承_%`（函数间传递引用类型变量）、`%_WS连接_%`、`%_请求数据_%`、`%_响应数据_%`。

## 构建 JSON

| 写法 | 用途 |
| --- | --- |
| `变量:{ ... }` / `变量:[ ... ]` | 写原样 JSON（`%变量%` 输出时自带引号） |
| `JSON>变量={}` / `JSON>[]` … `<JSON` | 按「键=值」逐行构建；键支持 `a->a=b` 多层路径、行尾不能带逗号，嵌数组 / 数字用 `键:=值` |

## 多行文本赋值（文本框赋值）

- 开启行写 `变量名:文本>行间分隔符`（等价写法 `文本>变量名=行间分隔符`），内容行逐行紧贴书写，闭合写 `<文本`。
- 整块内容按行间分隔符连接后赋给变量、本框不输出；分隔符写空则直接拼接，要真实换行写 `%换行%`。
- 多行 HTML / 长文本一律用这种写法一次赋值，**不要**用「`变量:` 置空 + `变量+:` 逐行累加」。
- 需要内容里的 `%变量%` 原样保留、不被插值时，改用 `变量名:纯文本>行间分隔符 … <文本`（纯文本框内容一律原样，`$函数$` 同样不执行）。
- 开启行只写 `文本>` / `纯文本>`（不带变量名）时，就是普通输出框。
