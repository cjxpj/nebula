# 变量

1. 赋值写「变量名:值」，变量名裸写、不带 %；读取才写 %变量名%。同名追加用 变量+:值，相减用 变量-:值；变量::值 表示原样文本不解析；赋值行里的变量名写成 %变量%: 无效（实测：整行被当普通文本输出，变量根本没生成，后续读 %变量名% 会报「变量不存在」）；函数调用会直接返回结果（返回值就地替换在行内），只是为了输出结果时不要把「$函数 参数$」先赋值给变量再写一行 %变量%，直接写 $函数 参数$ 即可，只有结果还要复用（再输出、当参数、参与运算、写进文本块）时才赋值存起来；
2. 读 JSON 路径用 %@变量.键.键%；三目与回退只在赋值中生效：条件?真值:假值、值?:回退值；
3. 变量名不超过 32 字节；跨函数读写用 $全局变量 名 值$ / $全局变量 名$，线程级用 $线程变量$；
4. 算术与计算必须「先取中间变量、再参与运算」：函数参数里、算术表达式 [...] 里都不能再嵌套 $函数$。错误：$JSON存 %背包% 草鱼 %$JSON解析 ...$ + 1$、$延迟 [1000*$随机数 1 3$]$；正确：先 旧数量:$JSON解析 %背包% 草鱼$、秒:$随机数 1 3$ 拿到中间值，再 $JSON存 %背包% 草鱼 $计算 %旧数量% + 1$$、$延迟 [1000*%秒%]$；算术表达式 [...] 内不要写空格（整个 [...] 会被当成一个参数，但参数是按空格切分的）：错误 $延迟 [1000 * %秒%]$、$写 a.txt 值 [%旧值% + 1]$，正确 $延迟 [1000*%秒%]$、$写 a.txt 值 [%旧值%+1]$；
5. 赋空值写「变量名:」（冒号后直接留空），不要写 变量名:"" ：本语言没有字符串字面量，写成 变量名:"" 会把两个引号当普通字符存进变量，后续输出 / 拼接 / 渲染都会带上这两个引号（例如网页词库里 九宫格HTML:"" 会把 "" 直接显示到页面上）；空值变量内部就是空字符串，读 %变量名% 得到的是空字符串，需要重新累计的变量一律这样初始化（如 计数: 再 计数+:1）；
6. 变量名、触发词、函数名用有意义的中文或英文；「_」开头结尾的名字保留给系统魔术变量（自动注入、无需赋值，不要自己占用）：%__词库路径__% 当前执行的词库文件路径、%_继承_% 函数间传递引用类型变量、%_WS连接_%、%_请求数据_%、%_响应数据_%；
7. 构建 JSON 两种写法：变量:{ ... } / 变量:[ ... ] 写原样 JSON（%变量% 输出时自带引号）；JSON>变量={} / JSON>[] 按「键=值」逐行构建（键支持 a->a=b 多层路径，行尾不能带逗号，嵌数组/数字用 键:=值），闭合写 <JSON；
8. 多行文本赋予值（文本框赋值）：开启行写「变量名:文本>行间分隔符」，内容行逐行紧贴书写，闭合写 <文本。整块内容按行间分隔符连接后赋给变量、本框不输出，之后用 %变量名% 读取；变量名紧贴 : 书写、不写 %，文本> 之后的整段是行间分隔符、会做 %变量% 插值（要直接拼接就留空，要真实换行写 %换行%）。等价写法「文本>变量名=行间分隔符」同样支持，两者语义一致，任选其一。要给多行 HTML / 长文本一次性赋值一律用这种写法，不要用「变量: 置空 + 变量+: 逐行累加」；需要内容里的 %变量% 原样保留、不被插值时改用「变量名:纯文本>行间分隔符 … <文本」（纯文本框内容一律原样，$函数$ 同样不执行）。开启行只写「文本>」「纯文本>」不带变量名时就是普通输出框。
